Canvaでの作成手順
1
カスタムサイズで新規作成 Canvaトップ → 「カスタムサイズ」→ 幅1280 / 高さ670 px → 新しいデザインを作成
2
背景色を設定（Type選択） Type A → #0D0D1A / Type B → #FFFFFF / Type C → #1A1A1A
3
ブランドカラーをCanvaに登録 左メニュー「ブランド」→ カラーパレットに上記5色を追加しておくと毎回楽
4
タイトルテキストを配置 Noto Sans JP Bold 以上 / フォントサイズ60〜80px / 余白を大きく取る
5
数字・結果を強調テキストで追加 「37分→9分」「月3万円」などアクセントカラーで大きく表示
6
著者名を右下or左下に小さく 「佐伯亮 | @saekiryoai」を薄いグレーで入れる（ブランド認知の積み重ね）
7
テンプレとして保存 右上「…」→「テンプレートとして保存」→ 次回から流用できる
💡 時短のコツ：Type A・Bの2種類を作ったら、あとはタイトルと数字のテキストだけ変えて使い回す。デザインを毎回考えない。「このデザイン = 佐伯亮」という認知が積み重なるので、統一することに価値がある。
