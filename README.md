# 佐伯亮 SNS運用会社 - 使い方ガイド

## セットアップ（初回のみ）

```bash
# 1. このフォルダをClaudeCodeで開く
cd saeki-ryo-company
claude

# 2. 会社の概要を読み込ませる（初回）
# → CLAUDE.mdを自動で読んでくれます
```

---

## 毎日の使い方（25分以内）

### 朝（10分）
```bash
# Claude Codeを起動
claude

# 秘書に話しかける
/company
「今日やること教えて。昨日〇〇をやって気づいたことがあって...」

# または直接スキルを呼ぶ
skills/skills.md の「朝の投稿準備」をコピペ実行
```

### 確認・投稿（10分）
- `logs/content/今日の日付.md` を開いて投稿文を確認
- 気に入ったものをXとスレッズに手動投稿
- （自動投稿はAPIの制限があるので手動が安全）

### 夜（5分）
```bash
# 秘書に今日の振り返りを渡す
「今日〇〇を投稿したら〇いいねついた。〇〇のネタが反応よかった気がする」
```

---

## ネタが浮かんだとき（いつでも）

```bash
# 思いついたらすぐ秘書に投げる
「ネタメモ：Claude Codeで〇〇をやったら思ったより〇〇だった」

# → 秘書がログに保存 → コンテンツ部が投稿化
```

---

## 週1でやること（20分）

```bash
# 週間スケジュール作成
skills/skills.md の「週間スケジュール作成」を実行

# リサーチ部への依頼
「今週のAIトレンドを調べて、来週使えるネタをリストアップして」
```

---

## フォルダ構成

```
saeki-ryo-company/
├── CLAUDE.md                    ← 会社の方針（触らない）
├── README.md                    ← このファイル
├── employees/
│   ├── secretary/CLAUDE.md      ← 秘書マニュアル
│   ├── research/CLAUDE.md       ← リサーチ部マニュアル
│   ├── content/CLAUDE.md        ← コンテンツ部マニュアル
│   └── scheduler/CLAUDE.md      ← スケジューラー部マニュアル
├── skills/
│   └── skills.md                ← コピペで使うスキル集
└── logs/                        ← 自動生成されるログ
    ├── secretary/
    ├── research/
    ├── content/
    └── scheduler/
```

---

## よくある使い方

**「投稿したいネタがある」**
→ 秘書に話す or スキル2「実体験→投稿変換」を使う

**「ネタが浮かばない」**
→ スキル1「朝の投稿準備」でリサーチログからネタ出し

**「バズ投稿を見た、参考にしたい」**
→ スキル5「バズ投稿分析→自分ネタ化」

**「note記事を書きたい」**
→ スキル3「note記事生成」

**「今週の投稿を一気に計画したい」**
→ スキル4「週間スケジュール作成」
