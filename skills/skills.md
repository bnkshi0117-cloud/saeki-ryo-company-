# スキル集（Skills）

## 使い方
Claude Codeで `/skill [スキル名]` と入力するか、
下記の指示文をそのままコピペして使う。

---

## スキル1: 朝の投稿準備（所要5分）
```
以下の手順で今日の投稿を準備してください：
1. logs/research/ の最新ファイルからネタを3つ取得
2. 各ネタについてX用投稿文を1案ずつ生成（佐伯亮の文体で）
3. 最もおすすめの1本をスレッズ用に展開
4. logs/content/今日の日付.md に保存
5. 「今日投稿するならこれ」を1本だけ教えてください
```

---

## スキル2: 実体験→投稿変換
```
以下の体験談をX投稿とスレッズ投稿に変換してください：

[体験談をここに書く]

条件：
- AIっぽい表現は使わない
- 「革命」「最強」「爆速」禁止
- 失敗や迷いがあれば正直に入れる
- X版：140字以内
- スレッズ版：200〜400字
- 各2〜3パターン出す
```

---

## スキル3: note記事生成
```
以下のテーマでnote記事を生成してください：

テーマ：[テーマをここに書く]
実体験：[関連する自分の経験]
ターゲット：AI初心者〜中級者、副業に興味ある会社員

条件：
- 1,500〜2,500字
- 結論を最初に言う
- 失敗談・試行錯誤を必ず入れる
- Kindle or アプリへの導線を1箇所だけ（自然に）
- です・ます調、カジュアル寄り
```

---

## スキル4: 週間スケジュール作成
```
今週の投稿スケジュールを作成してください：

利用可能なネタ：
- [ネタ1]
- [ネタ2]
- [ネタ3]

条件：
- X: 月〜金の5本（土日は任意）
- スレッズ: 週3本
- note: 1〜2本
- scheduler/のフォーマットで出力
- 無理のない量に調整してください
```

---

## スキル5: バズ投稿分析→自分ネタ化
```
以下のバズ投稿を分析して、佐伯亮が実体験として語れるネタに変換してください：

[バズ投稿の内容をここに貼る]

出力：
1. なぜ伸びたか（構造・感情トリガー）
2. 佐伯亮の実体験で語れる角度（2〜3案）
3. X投稿の下書き（最も自然なもの1本）
```
