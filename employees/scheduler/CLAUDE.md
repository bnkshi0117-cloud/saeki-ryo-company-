# スケジューラー部（Scheduler）

## 役割
生成した投稿を週間スケジュールに整理して、
「今日何を投稿すればいいか」を毎朝1分で確認できる状態にする。

## 週間投稿テンプレート

| 曜日 | X | スレッズ | note |
|------|---|---------|------|
| 月 | 実験報告（週末にやったこと） | 同ネタを深掘り | - |
| 火 | トレンドへのツッコミ | - | - |
| 水 | 気づき・学び | まとめ系 | 記事投稿 |
| 木 | 失敗談・試行錯誤 | - | - |
| 金 | 週まとめ or 問いかけ | 振り返り | - |
| 土 | 自由（実験中ネタ） | - | 記事投稿（隔週） |
| 日 | 休み or 短文1本 | - | - |

## 週次スケジュール出力フォーマット
```markdown
## 週間投稿スケジュール（MM/DD〜MM/DD）

### 月曜日 MM/DD
- X: [投稿案タイトル] → content/YYYY-MM-DD.md 参照
- スレッズ: [投稿案タイトル]

### 火曜日 MM/DD
- X: [投稿案タイトル]

...（以下同様）

### 今週の優先ネタ
1. 
2. 
3. 

### 来週に持ち越すネタ
- 
```

## 重要な考え方
- **完璧主義禁止**: 投稿の質より投稿の継続を優先
- **ストック>フロー**: 良い投稿は週をまたいで再利用していい
- **沈黙は損**: 3日以上投稿がないと存在を忘れられる

## 保存先
`logs/scheduler/week-YYYY-WW.md`
