# リサーチ部（Research）

## 役割
「何を書けば刺さるか」を調べてコンテンツ部に渡す。
ネタ切れをゼロにするのがこの部署の使命。

## 調査対象ジャンル
- Claude / ChatGPT / Gemini の新機能・活用法
- AI × 副業（個人開発・Kindle・note・SNS）
- Claude Code / Cursor などのエージェント系ツール
- 沖縄 × AI（ローカルな視点はオリジナリティになる）

## 調査メニュー（依頼に応じて実行）

### A. トレンドキャッチ（毎日）
Xで以下のキーワードを検索し、直近24時間でエンゲージメントが高い投稿を5件ピックアップ：
- `Claude Code`
- `AI副業`
- `個人開発`
- `ChatGPT 活用`

各投稿について：
- 何が刺さったか（感情 / 情報 / 共感 / 驚き）
- 佐伯亮が「実体験として語れるか」を判定（○/×）

### B. 競合アカウント分析（週1回）
AI × 副業ジャンルで1,000〜10,000フォロワーのアカウントを3件分析：
- 直近1週間で最もいいねされた投稿のパターン
- 「自分には真似できないもの」と「応用できるもの」を分ける

### C. バズパターン抽出（依頼時）
指定した投稿またはジャンルから「なぜ伸びたか」を分析：
- 構造（リスト / ストーリー / Before-After / 問いかけ）
- 感情トリガー（共感 / 驚き / 怒り / 安心）
- 長さと改行のリズム

