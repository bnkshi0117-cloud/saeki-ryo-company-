# Claude Codeで初めてWebアプリを作った全記録【非エンジニア】

---

## コードが書けなくてもアプリは作れる（本当に）

「アプリを作りたいけど、自分にはコードが書けない」

ずっとそう思って諦めてきました。

でも今年、Claude Codeを使って実際にWebアプリをリリースしました。開発期間は約2週間。使ったのは主にターミナルとブラウザだけです。

---

## 自己紹介：私はエンジニアじゃない

まず前提として、私のスペックをお伝えします。

- 沖縄在住の会社員（ITとは無関係の職種）
- Kindle出版を8冊やってきた文系寄りの人間
- ChatGPTやClaudeは2年以上使っているが、プログラミングは独学で少しかじった程度
- JavaScriptもPythonも「なんとなく読める」レベル。書けはしない

「ノーコードツールじゃダメなの？」と思う方もいるかもしれません。

NoCodeツールも使いました。BubbleやAdaloも試しました。でも、作りたいものが少し複雑になったとき、壁にぶつかる。カスタマイズが難しくなる。調べてもドキュメントが英語で止まる。

Claude Codeは違いました。「日本語で話しかけたら、コードを書いてくれる」というシンプルな体験が、私には合っていたんです。

---

## Claude Codeとは何か、私なりの理解

公式の説明をそのまま引用してもつまらないので、私の感覚を書きます。

Claude Codeは「ターミナルで動くAIアシスタント」です。

チャット画面でやり取りするClaude.aiとは少し違います。ターミナル（黒い画面）を開いて、`claude`と入力すると起動します。そこから日本語で「こういうアプリを作りたい」と話しかけると、ファイルを作ったり、コードを書いたり、エラーを直したりしてくれます。

私が最初に感動したのは「ファイルを自分で操作してくれる」という点でした。

ChatGPTにコードを書いてもらっても、それを自分でコピーして、ファイルを作って、貼り付けて…という作業が必要でした。Claude Codeはそれを全部自分でやってくれます。

---

## 何を作ったか

「日報入力→週報を自動生成するWebアプリ」を作りました。

会社で毎週、週報を書くのが面倒で。日報を5日分書いたら、AIが週報のフォーマットに自動でまとめてくれるツールが欲しかったんです。既存のツールを探してみたけど、ぴったりのものがなかった。

機能はシンプルにしました：

- 日報を入力できるフォーム
- 5日分貯まったら週報を生成するボタン
- 生成された週報をコピーできるUI

技術スタックは結果的にこうなりました（自分で選んだわけではなく、Claudeが提案した構成です）：

- フロントエンド：React + TypeScript
- バックエンド：Supabase（データ保存）
- デプロイ：Vercel
- バージョン管理：GitHub

この組み合わせ、最初は正直何もわかりませんでした。でも作り終えた今は「なぜこの構成が選ばれたのか」は理解できています。

## 作り始める前の不安

「Claude Codeを使えば誰でも作れる」という情報は目にしていました。

でも正直、怖かったです。

ターミナルを開くだけで緊張する。`npm install`って何？`git push`って何？エラーが出たときに自分で解決できるのか？

やってみて気づいたことがあります。全部わからなくていい、ということ。

Claude Codeに「このエラーは何ですか？」と聞けば教えてくれる。「どうすれば解決できますか？」と聞けばコマンドを教えてくれる。私はただそれを実行するだけでよかった。

「理解する」より「動かす」を優先する。これが非エンジニアにとっての正しい順番だと思いました。

## 開発フロー：全体像

まず全体の流れを共有します。

私の場合、こういう順番で進みました：

1. Claude Codeのインストール（30分）
2. 要件を日本語で整理する（1時間）
3. Claudeに最初の指示を出す（30分）
4. エラーと格闘する（2日間）
5. UIを整える（3日間）
6. Supabaseの設定（半日）
7. GitHubにプッシュ→Vercelでデプロイ（2時間）

合計で約10日間、毎日1〜2時間作業した感じです。フルタイムで作ったら3日かからないかもしれません。

---

## STEP1：インストールと環境構築

Claude Codeはnpmでインストールします。

```
npm install -g @anthropic-ai/claude-code
```

これを実行するにはNode.jsが必要です。Node.jsが入っていない場合は、先に公式サイトからインストールしてください（LTS版を選べばOKです）。

インストール後、`claude`と打つと起動します。最初にAnthropicのAPIキーを聞かれます。claude.aiのアカウントがあればAPIキーを発行できます。

**私がつまずいたポイント①：APIキーの設定場所**

APIキーを発行したけど、どこに入力するのかわからなかった。答えは「claude起動時に聞かれる画面でそのまま貼り付ける」だけでした。環境変数の設定は不要です（最初からそう教えてほしかった）。

---

## STEP2：最初の指示文

Claude Codeを起動したら、新しいフォルダを作ってその中で作業します。

```
mkdir weekly-report-app
cd weekly-report-app
claude
```

そして私が最初に入力した指示文がこちらです：

---

**実際に使った最初のプロンプト：**

```
日報を入力して、5日分貯まったら週報を自動生成するWebアプリを作りたいです。

要件：
- 日報（その日やったこと、課題、明日やること）を入力できるフォーム
- 入力した日報が一覧で見られる画面
- 5日分の日報から週報を生成するボタン
- 生成された週報をコピーできる機能

技術スタックはシンプルなもので、初心者でもデプロイできる構成にしてください。
まず最初に何から始めるべきか教えて、それから実装を進めましょう。
```

---

このプロンプトで重要なのは「まず何から始めるか教えて」という一文です。

いきなり全部作らせようとすると、Claudeはファイルを大量に生成します。初心者にはその量が処理しきれない。「順番を説明してから動いて」と一言入れることで、ステップバイステップで進められます。

## つまずいたポイント8選と解決策

**① `npm run dev`を実行してもブラウザに何も表示されない**

原因：ポートが既に使われていた。
解決：`localhost:5173`ではなく`localhost:5174`にアクセスしたら表示された。Claudeに聞いたら「別のポートを使っています」と教えてくれた。

**② 日報を入力しても保存されない（リロードすると消える）**

原因：最初はlocalStorageに保存する実装だったが、設定が抜けていた。
解決：「保存されない」とClaudeに伝えたら、コードを修正してくれた。Supabase導入前の話。

**③ Supabaseの設定がわからない**

Supabaseはデータベースのサービスです。無料で使えます。
解決：ClaudeにSupabaseの設定手順を聞いたら、スクリーンショットなしでも手順を説明してくれた。「Supabaseのダッシュボードで○○という項目を探して、URLとAPIキーをメモしてください」という指示に従うだけでした。

**実際のプロンプト：**
```
Supabaseを使ってデータを保存したいです。
初めて使うので、アカウント作成からの手順を教えてください。
その後、このアプリに組み込む方法も教えてください。
```

**④ 環境変数（.envファイル）の設定**

SupabaseのAPIキーをコードに直接書くのはNG。`.env`ファイルに書く必要があります。
解決：Claudeが「.envファイルを作って、こう書いてください」と教えてくれた。`.gitignore`への追加も忘れずに（これもClaudeが言ってくれた）。

**⑤ GitHubへのプッシュでエラー**

`git push`したらエラーが出た。
原因：GitHubのリポジトリをまだ作っていなかった。
解決：GitHubでリポジトリを作成してから、Claudeの指示通りにコマンドを実行。

**⑥ Vercelのデプロイで環境変数が反映されない**

ローカルでは動くのに、Vercelにデプロイしたら動かない。
原因：`.env`ファイルはGitHubにプッシュされないため、Vercel側にも環境変数を設定する必要があった。
解決：VercelのダッシュボードでEnvironment Variablesを設定する画面があり、そこにSupabaseのURLとキーを入力。Claudeに「Vercelに環境変数を設定する方法を教えて」と聞いたら教えてくれた。

**⑦ 生成された週報の文体がおかしい**

週報の自動生成をGPT APIに依頼していたのですが、生成される文体が敬語だったり、箇条書きだったり、安定しなかった。
解決：プロンプトに「必ず体言止めで、○字以内で」と制約を入れたら安定した。

**⑧ スマホで見たときのレイアウト崩れ**

PCでは綺麗に見えるのにスマホで崩れた。
解決：「スマホでも見やすいように修正してください」と伝えたら、CSSを修正してくれた。「レスポンシブ対応」という言葉を知らなくても、日本語で伝えれば通じる。

## CLAUDE.mdの使い方

開発が進むと、Claudeに毎回「このアプリはこういう仕様で…」と説明するのが面倒になります。

そこで使えるのが`CLAUDE.md`というファイルです。

プロジェクトのフォルダに`CLAUDE.md`というファイルを作って、アプリの仕様や制約を書いておくと、Claudeがそれを参照してくれます。

**私が実際に書いたCLAUDE.mdの内容：**

```markdown
# 週報自動生成アプリ 仕様メモ

## アプリ概要
日報を入力して5日分で週報を自動生成するWebアプリ。
会社員が個人用に使うツール。

## 技術スタック
- フロントエンド：React + TypeScript
- DB：Supabase
- デプロイ：Vercel

## データ構造
- daily_reports テーブル：id, date, did, issue, tomorrow, user_id
- weekly_reports テーブル：id, week_start, content, created_at

## 注意点
- ユーザー認証は現在未実装（個人用なので不要）
- APIキーは.envに記述
- 生成AIにはOpenAI APIを使用

## UIの方針
- シンプルで白ベース
- ボタンは青（#3B82F6）
- スマホ対応必須
```

これを書いておくと、セッションをまたいでもClaudeが仕様を把握してくれます。「前に話したあの設定どうなってましたっけ」という確認作業が減ります。

## デプロイの手順（GitHub → Vercel）

**GitHubの手順：**

1. GitHubでアカウントを作成
2. New repositoryで新しいリポジトリを作成
3. ターミナルで以下を実行（Claudeが教えてくれた）

```
git init
git add .
git commit -m "first commit"
git branch -M main
git remote add origin https://github.com/ユーザー名/リポジトリ名.git
git push -u origin main
```

**Vercelの手順：**

1. vercel.comでアカウント作成
2. 「New Project」からGitHubリポジトリを選択
3. 環境変数を設定（Supabaseの情報）
4. Deployボタンを押す

5分以内に公開URLが発行されます。`.vercel.app`のドメインで誰でもアクセスできる状態になります。

## 非エンジニアが最初にやるべきこと

実際に作り終えて思う、最初にやるべきことを書きます。

**1. 作るものを1機能に絞る**

「あれもこれも」と考えると詰まります。「これだけできればいい」という最小限の機能で始める。後から追加するのは簡単です。

**2. わからない言葉はその場でClaudeに聞く**

`git`、`npm`、`React`、何でも聞いていい。「小学生に説明するつもりで教えてください」と言うと丁寧に教えてくれます。

**3. エラーはコピーしてそのままClaudeに貼る**

エラーメッセージを自分で解読しようとしない。そのままコピーして「このエラーが出ました。解決してください」で99%解決します。

**4. CLAUDE.mdを早めに作る**

開発が始まったら、すぐに仕様をCLAUDE.mdにメモする習慣をつける。後からまとめようとすると忘れます。

**5. 完璧を求めない**

デザインが少し崩れていても、まず動くものを作る。「後で直す」で十分です。完成させることがゴール。
