# フォロワー0から始めたX運用、AIを使って3ヶ月でどうなったか

---

## まず正直に言います

「SNS、ちゃんとやらなきゃな」と思い続けて、何もしないまま3ヶ月が過ぎた。

そういう経験、ありませんか。

僕はあります。何度も。アカウントを作って、数投稿して、反応がなくて、そのまま放置。そのサイクルを繰り返していました。

でも去年の秋、ちゃんと向き合うことにしました。フォロワー0のアカウントから、AIをフル活用してX運用を3ヶ月続けてみたんです。

結果をさきに言うと、フォロワーは1,200人を超えました。月間インプレッションは最初の月が約8,000で、3ヶ月目には230,000を超えました。「バズった」という感覚は一度もなかったけど、じわじわと数字が伸び続けました。

この記事では、何をどうやったかを正直に書きます。

---

## なぜ今まで続かなかったか

SNSが続かない理由って、だいたい同じだと思うんですよ。

「何を書けばいいかわからない」「書いても反応がない」「忙しくて時間が取れない」。

僕も全部当てはまってました。会社員をしながら副業をやっているので、平日の夜は正直ヘトヘト。「今日もツイートできなかった」という罪悪感だけが積み上がっていきました。

一時期、「毎日投稿するぞ」と気合いを入れたことがあります。最初の1週間はできた。2週目からペースが落ちた。3週目に完全に止まった。

続かない原因を掘り下げると、大きく2つありました。

**1つ目は「ネタ切れ」。** 日常を発信しようとしても、「自分の話なんて面白くないかな」という謎の遠慮が邪魔してくる。そのうち何も思い浮かばなくなる。

**2つ目は「完成度へのこだわり」。** 「もっといい文章にしてから投稿しよう」と思って、下書きが30個溜まったまま公開されない、という状態になっていました。

この2つを解決しないと、どんな気合いを入れても続かないんですよね。

---

## AIを使う前の試行錯誤

最初に試したのは、投稿テンプレートを使う方法でした。「共感→問題提起→解決策→行動促進」みたいなフォーマットを用意して、それに当てはめて書く。

これはそれなりに効果がありました。「何を書くか」という悩みが減ったから。

でも問題は、フォーマットに当てはめる文章を考える時間が、結局けっこうかかるということ。1投稿に20〜30分使っていました。毎日それをやると、週に3〜4時間がSNSに消えていく。

副業の作業時間を圧迫しはじめて、「これはちょっと違うな」と感じ始めました。

そこで本格的にAIを使う実験を始めたのが、3ヶ月前のことです。

---

## AI活用前の「準備」が全てだった

ここが一番大事なポイントなので、丁寧に書きます。

AIにいきなり「ツイートを書いて」と頼んでも、自分らしい文章にはなりません。最初にやったのは「自分の言葉の型」を整理することでした。

具体的には、過去に自分が書いた文章（メモ、メール、LINEの長文など）を読み返して、よく使うフレーズ・文のリズム・語尾のクセをピックアップしました。

僕の場合、こんな特徴があると気づきました。

- 文末に「〜だと思ってます」が多い
- 「でも」「だから」で文をつなぐ
- 数字を出すとき必ず「約○○」「だいたい○○」と書く
- 体験談の後に「これ、意外と大事でした」と結ぶことが多い

この「自分の癖リスト」をAIに渡す。それだけで、出力の質がガラッと変わりました。

「自分っぽくない」という違和感は、このステップを飛ばしたときに起きることがほとんどです。

---

## 3ヶ月の変化を正直に振り返る

**1ヶ月目：セットアップと試行錯誤**

最初の1ヶ月は、仕組みを作ることに時間を使いました。投稿のパターンを5種類決めて、それぞれのAIプロンプトを育てる。

フォロワーは0→87人。インプレッションは月8,000ほど。正直、数字は小さかったです。でもこの1ヶ月で毎日投稿の習慣がついた。これが一番の収穫でした。

**2ヶ月目：型が安定し始める**

プロンプトが固まってきたので、投稿の質が安定してきました。「今日はこのパターンで行こう」と決めたら、AIが8割の草稿を出してくれて、自分は2割の調整をするだけで投稿できる。

1投稿あたりの時間が、30分→10分以下になりました。フォロワーは87→520人。月間インプレッションは約65,000。

**3ヶ月目：「自分の声」が定着してきた**

AIが出してくる文章に、自分の感覚で調整を入れ続けると、だんだん最初の草稿自体が自分に近くなってきます。プロンプトが育ってきたというか、AIが「佐伯っぽい書き方」を学習してくれた感じ。

月末にはフォロワー1,200人超え。月間インプレッション230,000。

繰り返しますが、バズったわけじゃないです。じわじわ積み上がった結果です。

---

## 「自動化」と「自分らしさ」は両立できる

よく言われることとして、「AIを使うと文章が均質化する」という懸念があります。

これ、半分正しくて半分違うと思っています。

プロンプトを適当に使うと確かに均質化します。でも「自分の型」をちゃんと渡して、毎回リライト・調整を入れると、逆にブレが減って「一貫した自分の声」が出やすくなる。

手書きで書いていたときの方が、実は日によって文章のトーンがバラバラでした。気分がいい日と疲れた日で、明らかに文体が違う。AIを使い始めてから、「この人はいつもこう書くな」という一貫性が出てきたと、フォロワーの方に言ってもらえたことがありました。

これは想定外の効果でした。

---

## 続けられた本当の理由

最後に、続けられた理由を正直に言います。

「AIのおかげ」というのはもちろんあります。でも一番大きかったのは、「完璧じゃなくていい」と割り切れたことだと思っています。

AIが草稿を出してくれると、「ここから自分が仕上げる」という感覚になる。手で書いているときは「これで全部自分が責任を持たないと」というプレッシャーがあったんですが、草稿がある状態だと気持ちが軽くなる。

それで「80点で出す」習慣がつきました。

SNS運用を3ヶ月続けて、一番変わったのは「発信への心理的ハードル」です。今は投稿するのが普通になっています。それが数字以上の変化だと感じています。

## 実際に使っているプロンプトの構造

まずベースとなるプロンプトの構造を公開します。

僕が毎回使っているプロンプトは、3つのブロックで構成されています。

```
【キャラクター定義ブロック】
あなたは佐伯亮の代筆AIです。
以下の文体ルールを厳守してください。

・一文は60字以内
・「でも」「だから」で文をよくつなぐ
・体験談ベースで書く
・「〜だと思ってます」「〜でした」が語尾に多い
・数字は必ず入れる（「たくさん」は使わない）
・煽り表現（「最強」「爆速」「革命」）は使わない

【テーマ・ネタブロック】
今日のテーマ：[ここに当日のネタを1〜2行で書く]
投稿パターン：[後述の5パターンから選ぶ]

【出力指定ブロック】
140字以内のツイートを3案出してください。
各案の末尾に、改善ポイントを1行で添えてください。
```

このプロンプトに「今日のネタ」と「パターン」を入れるだけで、1分以内に草稿が出てきます。

使っているのはClaudeとChatGPTを両方です。体感的に、Claudeの方が文体の再現精度が高いと感じています。特に「語尾の統一」がClaudeの方が安定していました。

## 投稿の5パターンと使い分け

3ヶ月で固まった投稿パターンは5種類です。

**パターン1：失敗→学び型**

```
形式：「〇〇をやって失敗した。原因は△△だった。今は□□している。」
使う頻度：週2回
特徴：エンゲージメントが一番高い。失敗談は共感を得やすい。
```

実例のインプレッション：1投稿平均で約4,200。

**パターン2：数字で語る型**

```
形式：「〇〇が△△から□□になった。変えたのは1つだけ。」
使う頻度：週1〜2回
特徴：シェアされやすい。「具体的な数字」が引き。
```

実例のインプレッション：1投稿平均で約5,800。このパターンが一番伸びました。

**パターン3：問いかけ型**

```
形式：「〇〇している人に聞きたいんですが、△△ってどうしてますか？」
使う頻度：週1回
特徴：返信・エンゲージメントが上がる。フォロワーとの対話が生まれる。
```

**パターン4：ミニノウハウ型**

```
形式：「〇〇するときのコツ、3つ。1.△△ 2.□□ 3.◇◇」
使う頻度：週1〜2回
特徴：保存率が高い。フォロワー増加に貢献しやすい。
```

**パターン5：近況シェア型**

```
形式：「今日、〇〇をやってみた。結果は△△だった。」
使う頻度：週1回
特徴：「人間らしさ」が出る。他のパターンとのバランス調整に使う。
```

この5パターンを週5〜6投稿に配分しています。毎週日曜夜に翌週分を決める。「今週はパターン2が少ないな」と気づいたら補う。これだけでネタ切れがほぼなくなりました。

## ネタを切らさないための「ネタ帳の仕組み」

「毎日投稿のネタをどこから持ってくるか」はよく聞かれる質問です。

僕がやっているのは、「ネタのトリガーを決める」という方法です。

日常の中で「あ、これ投稿できそう」と思う瞬間はあるんですが、忘れるんですよ。だから、以下の3つのタイミングでメモを取るルールにしました。

- 仕事中に「不便だな」と思った瞬間
- 何かを試して「意外と良かった」と思った瞬間
- 誰かに「それどうやってるの？」と聞かれた瞬間

これをiPhoneのメモアプリに1行でいいので書く。週末にそれをまとめて、AIにかける。

「このメモをもとに、投稿ネタを5案出してください」というプロンプトを使います。1週間に10〜15個のメモが溜まれば、投稿ネタは余るくらい出てきます。

## 文体を保ちながらAIに書かせるコツ（補足）

実際にやっていて効果があった細かいテクニックを補足します。

**「NG表現リスト」をプロンプトに入れる**

AIはどうしても「ぜひ」「〜しましょう」「非常に」などの言い回しを多用します。これが自分の文体と合わないと感じたので、プロンプトに「以下の表現は使わないでください：ぜひ、〜しましょう、非常に、重要です」というリストを追加しました。これだけで「AIっぽさ」がかなり消えます。

**3案出してもらって「一番自分に近い感じ」を選ぶ**

1案だけ出してもらうより、3案の中から選ぶ方が結果的に速いです。気に入らなければ再生成ではなく、「この3案の中で〇〇の要素を残しつつ書き直して」と指示すると精度が上がります。

**投稿後に「今日の反応」をメモする**

どの投稿がどれくらい伸びたか、週次でメモしています。「パターン2が今週よく伸びた」という気づきを次のプロンプトに反映する。このサイクルが、プロンプトを育てる一番の方法です。

## 今日から使えるスターターキット

まとめとして、すぐ使えるプロンプトのテンプレートをそのまま渡します。

```
【キャラクター設定】
あなたは[自分の名前]の代筆AIです。

文体ルール：
- 一文は60字以内
- [自分がよく使う接続詞]で文をつなぐ
- 体験談ベースで書く
- 数字を必ず入れる
- 以下の表現は使わない：ぜひ、〜しましょう、非常に、重要です

[自分のキャラクターを表す文章を3〜5文で記述]

【今日のネタ】
[1〜2行でメモしたネタを貼り付ける]

【投稿パターン】
[失敗→学び型 / 数字で語る型 / 問いかけ型 / ミニノウハウ型 / 近況シェア型]から選ぶ

【出力指定】
140字以内のツイートを3案出してください。
各案の末尾に、改善ポイントを1行で添えてください。
使わないでください：ぜひ、〜しましょう、非常に、重要です
```

[ ]の中を自分の情報に書き換えるだけで使えます。

最初の1週間は、このテンプレートをそのまま使ってみてください。「なんか違う」と感じたところを少しずつ調整していくと、2週間もすれば自分仕様のプロンプトになります。

## 最後に

3ヶ月でフォロワー1,200人という数字は、インフルエンサーに比べれば全然小さいです。でも、「続けること」「自分の声で発信すること」という点では、過去最高の結果でした。

AIを使っても、発信するのは結局自分です。AIはあくまで「草稿を出してくれるアシスタント」。最後に調整して、投稿ボタンを押すのは自分。そのバランスがうまくいくと、発信がしんどくなくなります。

続かない理由があるなら、その理由を一つ潰せばいい。僕は「時間がかかる」「ネタ切れ」この2つをAIで解決しました。

まずは1週間、試してみてください。
