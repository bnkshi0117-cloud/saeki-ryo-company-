# Claudeを使ったSEO記事で副業収入を作るまでの全手順

---

## 「AIで記事を書けば稼げる」は半分本当で、半分は嘘だった

正直に言います。

最初の1ヶ月、ほぼ何も稼げませんでした。Claudeを使い始めて、記事を量産して、クラウドワークスに片っ端から応募した。でも採用されない。されても文字単価0.5円の案件しかなかった。

「AIで副業収入」という言葉だけを信じて動いたら、普通に詰まります。

ただ、3ヶ月後には月3〜4万円の収入が安定して入るようになりました。仕組みを変えたからです。今回は、沖縄でフルタイム会社員をしながら、ClaudeでSEO記事を書いて副業収入を作るまでの全手順を書きます。

うまくいったことも、失敗したことも、全部正直に。

## 自分の話をすこしだけ

沖縄在住、会社員の佐伯亮です。副業を始めたのは3年ほど前。最初はKindle出版をやっていました。

Kindleは今でも続けていて、8冊出しています。ただ、Kindleは1冊書くのに2〜3週間かかる。それで月5,000〜8,000円くらいの印税。時給換算するとかなり厳しい数字でした。

Claudeを本格的に使い始めたのは約1年前。最初は「ライティングを速くする補助ツール」として使っていたんですが、SEO記事との組み合わせに可能性を感じ始めて、副業の軸を移していきました。

現在は、SEO記事の受注 + 自分のブログへのコンテンツ投下 + note販売という3本柱で動いています。

## AI副業の現実：甘くない部分を正直に

Claudeを使えば記事がラクに書ける。これは本当です。

以前は1,000字の記事に1時間かかっていたのが、今は2,000字の記事を30〜40分で仕上げられます。スピードは確実に上がった。

でも、スピードが上がっただけでは稼げません。理由は3つあります。

**① 低単価案件の沼にはまる**

クラウドワークスやランサーズで「AIライティング」と検索すると、文字単価0.3〜0.8円の案件がずらっと出てきます。2,000字で600〜1,600円。時間をかけずに書けるといっても、月10万円稼ごうとしたら相当な量をこなさないといけない。本業との両立は、現実的に無理です。

**② AIが書いた文章はすぐわかる**

Claudeに「〇〇について記事を書いて」と丸投げすると、なめらかだけど個性のない文章が出てきます。発注者もクライアントもAI文章には慣れてきていて、「コレ、そのまま貼り付けたな」とすぐバレる。修正・リライトのスキルがないと通用しない。

**③ SEOの基礎知識がないと記事が無駄になる**

キーワードの選定、検索意図の把握、見出し構成。これができていないと、Claudeが出力した文章をどう使えばいいかわからない。記事は書けても、誰にも読まれない。

この3つを突破できるかどうかが、AI副業で稼げる人と稼げない人の分岐点だと思っています。

## Claudeを使ったSEO記事の作り方：基本の流れ

ここからは、自分が実際にやっている手順を書きます。

### ステップ1：キーワード選定

まずGoogleサジェストとUbersuggestを使います。狙うのは月間検索数500〜3,000件くらいのミドルキーワード。競合が少なくて、でも一定の需要があるところ。

例えば「Claude 使い方 副業」とか「SEO記事 外注 注意点」とか。大きいキーワードに突っ込んでも、個人ブログでは太刀打ちできません。

### ステップ2：上位記事の検索意図を読む

キーワードを決めたら、Googleで実際に検索して上位5記事を読みます。読むのは構成と見出しだけでいい。「このキーワードで検索している人は何を知りたいのか」を掴むのが目的です。

ここをサボると、どれだけいい記事を書いても的外れになります。

### ステップ3：Claudeに見出し構成を作らせる

このプロンプトを使っています。

```
以下の条件でSEO記事の見出し構成を作ってください。

・ターゲットキーワード：[キーワード]
・検索意図：[想定読者が知りたいこと]
・文字数：2,000〜2,500字
・H2見出しを3〜4つ、各H2の下にH3を2〜3つ
・読者の悩みを解決する順番で構成すること
```

Claudeが出してきた構成を、自分で上位記事と照らし合わせて修正します。全部任せるんじゃなくて、「たたき台」として使うイメージです。

### ステップ4：セクションごとに本文を生成

見出しができたら、H2ひとつずつに分けて本文を生成します。一気に全部書かせるより、精度が上がります。

各セクションに必ず「実体験や具体例を入れる指示」を追加します。そうしないと、どこかで読んだような抽象的な文章になる。

### ステップ5：リライトと一次情報の追加

Claudeの出力をそのまま使わない。必ず自分でリライトします。

やることは2つ。

- AI的な言い回しを削る（「〜ことが重要です」「〜を意識しましょう」系）
- 自分の実体験を1〜2箇所追加する

この「一次情報を足す」工程が一番大事で、一番差がつくところです。

## 実際の収入の作り方：3つのルート

SEO記事で副業収入を作るルートは、自分の経験から3つあると思っています。

**ルート1：クライアントワーク（受注）**
クラウドワークスやランサーズで案件を受ける。即収入になる。ただし単価交渉が必要。

**ルート2：自分のブログで広告収入**
書いた記事をWordPressに投稿して、アドセンスやアフィリエイトで収益化。時間はかかるがストック型。

**ルート3：noteで記事販売**
記事そのものを商品にする。今読んでいるこの記事がそれです。

自分は3つ全部やっています。ただ、最初に収入を作るなら、ルート1から入るのが一番早い。

### 単価を上げるために変えた3つのこと

#### 1. 応募文を全面的に書き直した

最初の応募文は「AIを使って効率的に記事を作成できます」みたいな感じで書いていました。これは逆効果だったと思います。

発注者が不安なのは「AIが書いた粗い文章を納品されるんじゃないか」というところ。なので応募文を「SEOを意識した構成設計と、一次情報を含むリライト込みで対応します」という書き方に変えた。

「AIを使う」は隠しつつ、「ライターとしての価値」を前に出す形です。

採用率が体感で2〜3倍上がりました。

#### 2. ポートフォリオを3本用意した

応募時に自分のブログ記事3本をポートフォリオとして添付するようにした。

記事の内容よりも「見出し構成が論理的か」「文体が統一されているか」を見られていると感じます。Claudeの出力をそのまま貼り付けた記事と、ちゃんとリライトした記事は、読めばわかる。ポートフォリオで差別化できます。

#### 3. 文字単価0.8円以下の案件は受けないと決めた

これが一番大事でした。

低単価案件をこなすほど時間を取られて、スキルアップの時間がなくなる。時間がなくなるとポートフォリオも更新できない。悪循環です。

「文字単価1.2円以上の案件だけ受ける」と決めてから、応募数は減ったけど採用率は上がりました。安売りしないこと、これは副業でも大事な原則でした。

### 実際に使っているプロンプトテンプレート（全文公開）

以下が、現在メインで使っているプロンプトです。

**① 見出し構成生成プロンプト**

```
あなたはSEOに強いコンテンツライターです。
以下の条件で記事の見出し構成を作ってください。

【ターゲットキーワード】
[ここに入力]

【検索意図（読者が知りたいこと）】
[ここに入力]

【記事の対象読者】
[例：副業を始めたい30代会社員]

【文字数目安】
[例：2,500字]

【出力形式】
H1タイトル案を3つ
H2見出し：3〜4つ
各H2の下にH3を2〜3つ
各見出しに「なぜこの順番か」を1行で説明

注意点：
- 検索意図に沿った順番で構成すること
- 読者の疑問が解決される流れを意識すること
- 情報の重複がないこと
```

**② 本文生成プロンプト（セクション単位）**

```
以下の条件でH2セクションの本文を書いてください。

【見出し】
[H2見出しを入力]

【このセクションで伝えること】
[箇条書きで3〜5点]

【読者の状況】
[読者が今どういう状態か]

【文体】
・です・ます調
・一文は60字以内
・専門用語はなるべく避ける
・具体例や数字を1つ以上含める

【文字数】
500〜600字

注意：
「〜することが重要です」「〜を心がけましょう」のような
抽象的な締め方は避けること。
具体的な行動で終わらせること。
```

**③ リライト用プロンプト**

```
以下の文章をリライトしてください。

【リライト前の文章】
[Claudeが生成した文章を貼る]

【リライトの方針】
・AI的な言い回しを削除する
・より会話に近い自然な文体にする
・「まず」「次に」「そして」の多用をなくす
・一文が長い場合は分割する
・体言止めを適度に混ぜる

【禁止ワード】
・〜ことが大切です
・〜を意識することが重要です
・〜してみましょう
・非常に、とても（多用）
```

この3つのプロンプトをセットで使うことで、記事の品質が安定してきました。

### 失敗した3つのパターンと、その原因

#### 失敗1：記事の量を増やすことに集中しすぎた

最初の1ヶ月、「とにかく記事数を増やせば稼げる」と思って、質より量で動いていました。1日3〜4記事を量産していた。

結果：どの記事も検索順位がつかず、クライアントからの評価も低い。時間だけ使って収入につながらなかった。

**改善策：**
月10本の記事を、月3本に減らして丁寧に仕上げる方針に転換。1本にかける時間を増やした結果、採用率と検索順位の両方が改善しました。

#### 失敗2：キーワードを雑に選んでいた

「副業 稼ぎ方」「SEO 方法」みたいなビッグキーワードを狙い続けた時期があります。

当然、個人ブログでは上位表示なんかできない。アクセスが来ない記事がどんどん積み上がっていくだけ。

**改善策：**
「月間検索数300〜1,000件 × 競合が個人ブログばかり」というキーワードに絞った。時間はかかるが、3ヶ月後に上位表示が出始めました。

#### 失敗3：ツールにお金をかけすぎた

副業を始めた頃、SEOツールやAIツールに月2万円近く使っていた時期がある。

結果：毎月の固定費が重くなって、収入が出ても手元に残らない。

**改善策：**
使うのはClaude Pro（月3,000円）とUbersuggest（月3,000円）の2つだけに絞りました。無料ツール（Googleサーチコンソール、Googleキーワードプランナー）と組み合わせれば、十分に回ります。

### 再現性のある仕組みの作り方

「1回稼いで終わり」じゃなくて、継続的に収入が入る状態を作るには、3つの要素が必要だと感じています。

**① 継続案件を1本確保する**

単発案件を追い続けるのは疲弊します。1社でいいので、月5〜10本の記事を継続発注してもらえる関係を作る。そこが安定収入の柱になります。

そのためにやったのは、「納品後に改善提案を1つ送る」こと。「今回の記事、〇〇のキーワードも関連性が高そうでした。次回参考にしていただければ」みたいな感じで。仕事への本気度が伝わって、継続依頼につながりやすくなりました。

**② ストック収益を少しずつ育てる**

クライアントワークは時間を売っているので、体調が悪いと収入がゼロになる。ブログのアフィリエイト収益やnote販売は、一度作ったものが積み上がっていく。

割合で言うと、今は「クライアントワーク70%：ストック収益30%」くらいです。これを最終的に50:50にするのが目標です。

**③ 作業時間を固定する**

本業があるので、副業に使える時間は限られています。自分の場合、平日は朝6時〜7時30分の1時間半だけ。土曜日に3〜4時間まとめてやる。

時間が決まっていると、集中できます。「今日は気が向かないからやめとこう」という逃げ道がなくなる。

### まとめ：初月から動けるロードマップ

最後に、これから始める人向けに、月ごとの動き方をまとめます。

**1ヶ月目：環境整備と最初の1件**

- Claude Proを契約する（3,000円/月）
- Wordpressブログを開設する
- ポートフォリオ記事を3本書く
- クラウドワークスに登録、文字単価0.8円以上の案件に10件応募する
- 目標：1件採用される

**2ヶ月目：質を上げて単価交渉**

- 納品した記事にフィードバックをもらう
- ポートフォリオを更新する
- 文字単価1.0円以上の案件に絞って応募する
- ブログ記事を週1本更新する
- 目標：月収1〜2万円

**3ヶ月目：継続案件を獲得する**

- 既存クライアントに継続提案をする
- SEOキーワードの選定精度を上げる（上位表示を1本出す）
- noteに記事販売を1本試す
- 目標：月収3万円

**4ヶ月目以降：仕組み化**

- クライアントワークと自メディアの割合を管理する
- 単価を1.5〜2円に上げる交渉をする
- 作業フローをテンプレート化して効率を上げる
- 目標：月収5万円の安定

沖縄という地方で、本業をこなしながら、Claudeとちゃんと向き合って作ってきた収入です。少しでも参考になれば嬉しいです。
