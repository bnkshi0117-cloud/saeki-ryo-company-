# ClaudeとNotionを組み合わせたら情報整理が劇的に変わった

---

## こんな使い方、してる人ほぼいないと思う

Notionって、使い始めたはいいけど気づいたら「貯めるだけ」になってませんか。

自分もそうでした。ページ数だけ増えて、肝心なときに出てこない。「あの情報どこだっけ」で10分消える、あの感じ。

ClaudeをNotionと組み合わせたら、その悩みがほぼ消えました。具体的に何をどう変えたか、正直に書きます。

---

## 最初のきっかけは「Notionへの絶望」だった

副業でアプリ開発とKindle執筆を並行している関係で、インプット量がとにかく多いです。

- 技術記事のメモ
- 書籍のハイライト
- ビジネスのアイデア走り書き
- 打ち合わせの議事録

これ全部Notionに突っ込んでいたんですが、半年経ったころには完全にカオスでした。

ページ数は300を超えていたと思います。タグもつけてたんですが、付け方がバラバラで機能してない。データベースも作ったけど途中で管理が面倒になって放置。

決定的だったのは、ある日「沖縄の補助金制度についてメモしたやつ」を探すのに20分かかったとき。しかもそのあと見つからなかった。

「Notionって、結局ただのゴミ箱じゃないか」と思いました。

---

## ChatGPTも試したけど、ここで詰まった

最初はChatGPTにNotionのエクスポートデータを貼り付けて整理してもらおうとしました。

でも問題が2つ出た。

**1つ目：トークン上限にすぐ引っかかる。**
Notionのページをまとめてエクスポートしてテキスト化すると、すぐ数万文字になります。ChatGPT（GPT-4）のコンテキストウィンドウでは途中で切れる。

**2つ目：指示の精度が低い。**
「このメモを整理して」と投げると、それっぽい出力は来るけど、自分の思考の癖とか優先順位を全然反映してくれない。汎用的すぎる。

ClaudeのProプランに切り替えたのはこのタイミングです。

理由は単純で、**コンテキストウィンドウが当時でも20万トークン近くあった**から。Notionの大量テキストを一気に読ませられる、というのが決め手でした。

---

## ClaudeとNotionの組み合わせで何が変わったか

実際に試して変わったことを3つ書きます。

### ① バラバラなメモが「問いに答えられる状態」になった

以前は情報を「保存する」ことで満足していました。

今は違います。Notionに溜まったメモをClaudeに読ませて、「このメモ群から、自分が副業でやるべき優先度の高いことを3つ教えて」という問いを投げます。

すると、自分では気づいていなかった共通テーマが浮き上がってくる。

たとえば先月、バラバラに書いてた開発メモをClaudeに読ませたら「UI改善より通知機能の実装を先にすべき根拠が3か所のメモに出ています」と返ってきた。自分では気づいてなかったパターンです。

### ② 議事録の整理が3時間から20分になった

打ち合わせ後の議事録整理、めんどくさくないですか。

以前は手書きメモをNotionに転記して、要点をまとめて、次のアクション書いて、で1件あたり30〜60分かかっていました。

今は音声メモを文字起こし（Whisperを使ってます）して、そのテキストをClaudeに投げるだけ。フォーマットを事前に指定しておけば、Notionに貼れる状態の議事録が2〜3分で出てきます。

月に10〜15件の打ち合わせがあるので、月3時間以上は浮いています。

### ③ 「週次レビュー」が機能するようになった

GTDの週次レビューってずっとやろうとして挫折してました。時間かかるし、何を見ればいいかわからなくなるから。

今は週1回、その週に追加したNotionのページをまとめてエクスポートしてClaudeに渡します。「この1週間で特に重要だったことと、来週に持ち越すべき課題を教えて」と聞くと、10分以内にレビューが終わります。

続けられるようになったのは、**考える負荷をClaudeに外注したから**だと思います。

## なぜClaudeが合っていたか、正直な感想

ChatGPTを否定したいわけじゃないです。用途によって向き不向きがある。

Claudeが自分のNotion整理に合っていた理由は3つです。

**長文を嫌がらない。**
2万字超のテキストを貼り付けても、途中で「要約します」とか言わずにちゃんと読んでくれる印象がある。ChatGPTは長文になると出力が雑になることがあった。

**指示のニュアンスを汲む精度が高い。**
「ビジネス視点で重要なものを」「技術的に実装難易度が高そうなものを除いて」みたいな複合条件の指示が伝わりやすい。

**文体が落ち着いてる。**
自分の文章スタイルに合わせた出力を求めると、余計な装飾が少ない。ビジネス文書に使いやすい。

ただ、完璧じゃないです。失敗した点も含めて、有料パートに詳しく書きます。

## 実際に使っているプロンプト全文（3種類）

### プロンプト①：議事録整理

```
以下は打ち合わせの音声文字起こしです。
次のフォーマットで整理してください。

【日付】
【参加者】
【決定事項】（箇条書き、3〜5項目）
【アクションアイテム】（担当者・期限付きで）
【次回までの確認事項】

出力はNotionに貼れるMarkdown形式で。
余計な前置きは不要です。

---文字起こし開始---
（ここにテキストを貼る）
```

ポイントは「余計な前置きは不要」という一文。これがないと「承知しました！以下にまとめます。」みたいな不要な文が毎回入ってくる。

### プロンプト②：Notionメモからの洞察抽出

```
以下は私のNotionメモです。職業は会社員で副業としてアプリ開発とKindle執筆をしています。
沖縄在住、使える時間は平日2時間、休日5時間程度です。

このメモ全体を読んで、以下を教えてください。

1. 繰り返し出てきているテーマや課題（3つまで）
2. 今の自分が最優先で取り組むべきこと（1つだけ、根拠付きで）
3. 見落としているリスクや盲点（気づいたことがあれば）

---メモここから---
（Notionのエクスポートテキストを貼る）
```

「沖縄在住、使える時間は…」という自己情報を入れるのが重要です。コンテキストがないと汎用的な回答しか返ってこない。

### プロンプト③：週次レビュー用

```
以下は今週（○月○日〜○月○日）に私が書いたNotionのメモです。

このメモをもとに週次レビューを行います。
以下の問いに答えてください。

Q1：今週うまくいったこと、または前進したことは何ですか？
Q2：今週消化できなかったタスクや課題は何ですか？
Q3：来週の最優先事項は何にすべきですか？（1つだけ）
Q4：このメモの中で、後から重要になりそうな情報はありますか？

出力はシンプルに。Q1〜Q4の形式のまま答えてください。

---今週のメモ---
（ここに貼る）
```

このプロンプトを毎週日曜夜に実行するようにしました。所要時間は貼り付け含めて10〜15分です。

## NotionとClaudeをつなぐワークフローの全手順

手順は大きく4ステップです。

**ステップ1：Notionのエクスポート**

Notionの「設定」→「エクスポート」からMarkdown形式でエクスポートできます。

ただし注意点があります。Notionのエクスポートはページ単位か、ワークスペース全体かを選べますが、**ワークスペース全体だとファイル数が多くなりすぎて扱いにくい**。

おすすめは「整理したいデータベースや親ページを1つ選んでエクスポートする」方法です。

**ステップ2：テキスト化**

エクスポートしたMarkdownファイルをテキストエディタで開いて、そのままコピー。

画像は無視していいです。Claudeはテキスト情報があれば十分機能します。

**ステップ3：Claudeに投げる**

Claude.ai（ブラウザ版）を使う場合は、プロジェクト機能を使うと便利です。

プロジェクトに「自分のプロフィール情報」を保存しておくと、毎回コンテキストを書かなくて済みます。

**ステップ4：出力をNotionに戻す**

Claudeが出力したMarkdownをそのままNotionに貼り付けるだけ。NotionはMarkdownに対応しているので、見出しや箇条書きがそのまま反映されます。

## 失敗した3パターン、正直に書く

うまくいかなかったことも書きます。

**失敗①：全ページをまとめて投げた**

最初、Notionのワークスペース全体をエクスポートしてClaudeに投げました。

20万トークン以上になって、Claudeが処理しきれずに途中で回答が切れました。また、情報が多すぎて「どこを見ていいかわからない」状態になった。

改善策：投げるのは直近1ヶ月分か、特定のプロジェクトに絞る。1回の入力は5万〜10万字程度が安定します。

**失敗②：プロンプトが曖昧すぎた**

「このメモを整理して」だけだと、出力がバラバラになります。毎回フォーマットが違うから、Notionに戻したときに統一感がない。

改善策：出力フォーマットを必ずプロンプトに明記する。「Markdownで」「箇条書きで」「3項目以内で」という制約を入れると安定します。

**失敗③：出力を信用しすぎた**

Claudeが「このメモには〇〇というパターンがあります」と言っても、自分のメモを読み返すとそうじゃないことがありました。

ハルシネーションというより、「自分の書き方が雑すぎてClaudeが誤読した」ケースが多かったです。

改善策：Claudeの出力は「ドラフト」として扱う。最終判断は自分でする。あくまで補助ツールです。

## Claude APIで半自動化した方法（コード付き）

毎回ブラウザでコピペするのが面倒になってきたので、Pythonスクリプトで半自動化しました。

Claude APIを使います。料金は1回の処理で数円〜十数円程度です。月に何十回も使っても数百円に収まる。

```python
import anthropic
import os

client = anthropic.Anthropic(api_key=os.environ.get("ANTHROPIC_API_KEY"))

def process_notion_memo(memo_text: str, prompt_type: str) -> str:
    
    prompts = {
        "weekly_review": f"""
以下は今週私が書いたNotionのメモです。
週次レビューとして、以下の問いに答えてください。

Q1：今週うまくいったこと、または前進したことは何ですか？
Q2：今週消化できなかったタスクや課題は何ですか？
Q3：来週の最優先事項は何にすべきですか？（1つだけ）
Q4：このメモの中で、後から重要になりそうな情報はありますか？

---メモ---
{memo_text}
""",
        "insight": f"""
以下は私のNotionメモです。
副業でアプリ開発とKindle執筆をしている会社員です。

このメモ全体から以下を教えてください。
1. 繰り返し出てきているテーマ（3つまで）
2. 最優先で取り組むべきこと（1つ、根拠付きで）
3. 見落としているリスクや盲点

---メモ---
{memo_text}
"""
    }
    
    message = client.messages.create(
        model="claude-sonnet-4-5",
        max_tokens=2048,
        messages=[
            {"role": "user", "content": prompts[prompt_type]}
        ]
    )
    
    return message.content[0].text

# 使い方
with open("notion_export.txt", "r", encoding="utf-8") as f:
    memo = f.read()

result = process_notion_memo(memo, "weekly_review")
print(result)

# テキストファイルに保存
with open("weekly_review_output.txt", "w", encoding="utf-8") as f:
    f.write(result)
```

このスクリプトをcronで週1回自動実行するように設定しています。

Macの場合、crontabに以下を追加するだけです。

```bash
# 毎週日曜23時に実行
0 23 * * 0 cd /path/to/script && python notion_claude.py
```

完全に自動化はしていないです。Notionのエクスポートだけ手動でやっています。そのほうが「自分が意図した範囲のデータを使っている」という安心感がある。

## 応用編：CLAUDE.mdとの組み合わせ

Claude Codeを使っている方は、CLAUDE.mdにNotionの整理ルールを書いておくと便利です。

自分はCLAUDE.mdに以下を追記しています。

```markdown
## Notionメモの処理ルール
- 出力はすべてMarkdown形式
- 箇条書きは5項目以内
- 優先度の根拠を必ず書く
- 沖縄在住・会社員・副業2本のコンテキストで判断する
- 感情的な言葉（「すごい」「重要」）は使わず、具体的に書く
```

これを設定しておくと、毎回プロンプトに自分の情報を書かなくていい。Claudeが最初からこのルールで動いてくれます。
