# Threadsを副業の集客に使うための戦略をAIで設計した話

---

## 「Threadsって結局どう使えばいいの？」という状態から始まった

正直に言います。

Threadsを始めた当初、全然わかりませんでした。Xみたいに使えばいいのか、Instagramの延長なのか。投稿しても反応が薄くて、3日で放置しかけました。

でも沖縄でひとり副業をやっている身としては、集客できるSNSを一個でも増やしたい。そこでClaude（AIアシスタント）を使って、Threads運用の戦略を最初から設計し直してみたんです。

結果として、設計から3ヶ月後にThreadsのフォロワーが0→320人になり、そこからnoteのビューが月450→1,200に増えました。劇的ではないかもしれないけど、ほぼ放置に近い状態で達成できたので、仕組みとして機能していると感じています。

今回はその戦略設計のプロセスを全部書きます。

---

## なぜXではなくThreadsを選んだか

「どうせXでやればよくない？」という声はよく聞きます。

私もXはやっています。でも2024年後半から、Xのアルゴリズムが変わってきた体感があって、新規アカウントで伸ばすのがしんどくなってきました。インプレッションが読めない。有料プランに入らないと表示が下がる印象もある。

Threadsはまだプラットフォームが育ちかけの状態です。競合が少ない分、ちゃんと設計すれば伸びる余地がある。

あとThreadsはInstagramと連携しているので、Instagramにすでにフォロワーがいる人なら最初から有利です。私はInstagramのフォロワーが200人くらいいたので、そこからの流入も期待できました。

それと、Threadsのユーザー層は比較的落ち着いた雰囲気があります。炎上文化が少ない。副業や学びの話を発信するには居心地がいい。

そういった理由でThreadsを主戦場に選びました。

---

## AIを使わずにやっていた頃の限界

最初の1ヶ月は、戦略なしで直感投稿していました。

「今日はAIの話を書こう」「副業の話にしようかな」と思いつきで投稿していたら、コンテンツがバラバラになりました。

Threadsのフォロワーから見ると「この人は何を発信している人なのか」が伝わらない。フォローする理由が生まれない状態です。

また投稿のペースも不安定でした。仕事が忙しい週は3日空く。ネタが思い浮かばない日が続く。会社員しながら副業もやっていると、SNSに割ける時間は限られています。

このまま続けても集客につながらないな、と思ったのが2ヶ月目の終わりごろでした。

---

## ClaudeでThreads戦略を設計した話

方向転換のきっかけは、Claudeに「副業の集客としてThreadsをどう使うか、戦略を一から考えてほしい」と相談したことでした。

単なる「投稿のアイデアを出して」ではなく、**戦略設計から依頼する**のがポイントです。

私が入力したプロンプトはこんな内容でした。

```
あなたはSNSマーケティングの専門家です。
以下の条件でThreadsの運用戦略を設計してください。

【発信者プロフィール】
- 沖縄在住の会社員、副業でAI活用・Kindle出版・アプリ開発をしている
- ターゲット：AI・副業・アプリ開発に興味がある20〜40代
- 最終ゴール：noteやKindleへの誘導、信頼構築

【現状】
- Threadsフォロワー：ほぼゼロ
- 投稿頻度：不安定（週2〜5回）
- Instagramフォロワー：約200人

【制約】
- 1日に使える時間：30分以内
- 大量投稿は難しい

以下を出力してください：
1. ポジショニング（どんな人として認識させるか）
2. 投稿カテゴリ（何を何割くらい投稿するか）
3. 週間投稿スケジュール
4. フォロワーを増やすための初期アクション
5. noteへの誘導タイミング
```

このプロンプトを入れると、Claudeが10分かからずに戦略の骨格を出してくれました。

出力の中で特に参考になったのが「投稿カテゴリの比率」でした。

Claudeが提案してきた比率はこんな感じです。

- AI活用の実体験・気づき：40%
- 副業・働き方の話：30%
- 学びのアウトプット：20%
- 自己開示・日常（沖縄の話など）：10%

最初は「自己開示なんていらないかな」と思っていましたが、Claudeの説明によると「発信者の人となりが見えないとフォローする理由が弱くなる」とのこと。試しに沖縄ネタを混ぜてみたら、エンゲージメントが上がりました。

## 「誰として認識されるか」を先に決める重要性

戦略設計で一番大事だとわかったのが、ポジショニングです。

Claudeと対話しながら言語化したのが次の一文です。

**「沖縄在住の会社員が、AIを実際に使いながら副業をやっている様子をリアルに発信している人」**

これがThreads上での自分のポジションです。

AIの話をするアカウントはたくさんあります。でも「沖縄在住」「会社員」「実体験ベース」を組み合わせると、かなり絞り込まれます。差別化がしやすい。

このポジションを決めてからプロフィール文を書き直しました。

変更前：「AI・副業・アプリ開発について発信します」

変更後：「沖縄の会社員。AIを使いながら副業中。Kindle8冊/アプリ2本。実際に試したことだけ書きます」

この変更後から、フォロワーの定着率が上がった体感があります。フォローしてすぐ外れる人が減った印象でした。

---

## 投稿の型をAIで設計する

毎回ゼロから文章を書くのは続きません。

Claudeに依頼して「自分のポジションに合った投稿の型」を5パターン作ってもらいました。

**型の例（AI実体験型）**

```
◯◯をAIでやってみた。
結果：[具体的な変化]

やり方はシンプル。
1. [ステップ1]
2. [ステップ2]
3. [ステップ3]

気をつけること：[注意点]

詳しくはnoteに書いてます👇
[リンク]
```

この型に沿って書くと、投稿1本あたりの作成時間が15分→5分以下になりました。型があると「何を書くか」ではなく「型に何を当てはめるか」という作業になるので、速い。

## ネタ切れを防ぐ仕組み

投稿を続けるうえで一番つらいのがネタ切れです。

私は月1回、ClaudeにThreadsの投稿ネタを30個まとめて出してもらうようにしました。

プロンプトはシンプルで、「自分のプロフィールと投稿カテゴリを渡して、来月のネタを30個出して」という内容です。

30個あると、1日1投稿でも1ヶ月分がカバーできます。そこから自分で使えそうなものを選んで、週間スケジュールに落とし込む。

全部使う必要はありません。気乗りしないネタは捨てればいい。30個あれば15〜20個は使えるものが出てきます。

ここまでが無料パートで共有できる内容です。

戦略の骨格はつかめたと思います。ここから有料パートでは、**具体的なプロンプトの全文**と、**実際の投稿データ（3ヶ月分のインプレッション・エンゲージメント）**、それから**noteへの誘導を機能させるための投稿設計**を全部公開します。

「どんな文章でClaude に依頼したか」「どの投稿が反応よかったか」という泥臭い部分まで書いています。

## 週間スケジュールの設計と実際の運用

Claudeが提案してきた週間スケジュールをベースに、自分の生活リズムに合わせて調整したのが以下です。

**月曜日：AI実体験の投稿**
週の始まりに「今週はこれをAIで試した」という導入をする。

**水曜日：副業・働き方の話**
会社員しながら副業している現実感を出す日。

**木曜日：学びのアウトプット**
本や記事で学んだことを自分の言葉で整理して投稿。

**土曜日：自己開示・沖縄の話**
週末はやや軽い内容で、人となりを見せる。

**日曜日：noteへの誘導投稿**
「今週書いたnoteはこれです」という形で流入を促す。

これを3ヶ月続けた結果のデータはこちらです。

**3ヶ月間の実績データ**

| 月 | フォロワー数 | 月間インプレッション | エンゲージメント率 | noteへの流入 |
|---|---|---|---|---|
| 1ヶ月目 | 0 → 47人 | 2,300 | 3.2% | 月45PV |
| 2ヶ月目 | 47 → 162人 | 8,700 | 4.1% | 月280PV |
| 3ヶ月目 | 162 → 320人 | 19,400 | 5.3% | 月1,200PV |

2ヶ月目から急に伸びた理由は、「自己開示投稿」を入れ始めたことです。

沖縄の海の写真を1枚添えて「会社員やりながらAI触ってる沖縄在住です。よろしくです」という自己紹介投稿を出したら、いいねが通常の3倍くらいついて、そこからフォロワーが増え始めました。

コンテンツの話だけしていると「お役立ち情報アカウント」止まりで、人がフォローしにくい。人としての輪郭を出すことが大事だとわかりました。

## noteへの誘導を機能させる投稿設計

Threadsからnoteへの流入を増やすには、誘導の仕方に型があります。

私が試した中で最も機能したのが「問題提起→結論だけ言う→詳しくはnote」という流れです。

**機能した誘導投稿の例**

```
副業でSNSを集客に使うとき、
一番先に決めるべきことがあります。

それは「投稿のカテゴリと比率」。

これを決めずに始めると、
フォロワーが増えても全然集客にならない。

決め方はnoteに書いたので、よければどうぞ👇
[リンクをプロフィールから]
```

この型のポイントは「結論（答え）を先に言う」ことです。

「気になる人はnoteで」という引っ張り方だと読まれません。「答えを言ってから、詳しくはnoteで」にすると、noteに来た人の満足度も上がります。

逆に機能しなかった誘導はこれです。

```
副業の集客について新しいnoteを書きました！
よかったら読んでみてください👇
```

これはほぼ効果なしでした。「よかったら」というあいまいな誘導は動機が弱い。何の話かもわからない。

具体的な価値（問題と結論）を先に示してから誘導するのが基本です。

ネタ切れを防ぐために月1回使っているプロンプトを公開します。

```
# Threads投稿ネタ生成プロンプト（月次版）

以下のプロフィールと投稿カテゴリをもとに、
来月のThreads投稿ネタを30個生成してください。

## プロフィール
[自分のプロフィールを貼る]

## 投稿カテゴリ
- AI実体験（40%）
- 副業・働き方（30%）
- 学びのアウトプット（20%）
- 自己開示（10%）

## ネタの条件
- 1投稿あたり300字以内に収まる内容
- 「やってみたらこうだった」という体験ベース
- 専門用語は最小限
- 数字を含められるものはなるべく含める

## 出力形式
カテゴリ別に分けて、各ネタを1〜2行で説明してください。
タイトルと「何を書くか」を箇条書きで。
```

このプロンプトで出てきた30個から、「使えそう」「体験として語れる」「今月に書けそう」という基準で15〜20個を選びます。

選んだネタを週間スケジュールに当てはめると、その月の投稿計画が完成します。作業時間は月に1回、合計で30分くらいです。

## 文体・トーンを保つコツ

AIに文章を書かせると、自分の文体と違う感じになることがあります。

私が解決した方法は「自分の過去投稿を参考文として渡す」ことです。

```
以下の文体・トーンを参考にして、[テーマ]についての
Threads投稿文を書いてください。

【参考文（自分の過去投稿）】
---
副業を始めて1年経った。
最初は「AIがあれば楽勝」と思っていた。

実際は違った。
AIはあくまでツール。使う人間の設計がないと、
全然意味がない文章しか出てこない。
---

上記の文体の特徴：
- 短文中心
- 「やってみたら違った」という体験ベース
- 読者に語りかける感じ
```

このように過去投稿を参考文として渡すと、自分に近い文体でAIが書いてくれます。

毎回手直しはしますが、0から書くより格段に速いです。

## まとめ：今日からできること3つ

ここまで読んでくれてありがとうございます。

最後にActionableな内容だけ絞ります。

**1. ポジショニングを50字で言語化する**
「どんな人として認識されたいか」を先に決める。Claudeに壁打ちしながら言語化するのが速い。

**2. 投稿カテゴリと比率を決める**
「何でも発信」はポジションが定まらない。最初はカテゴリを3〜4個に絞る。

**3. 月1回の投稿ネタ生成を習慣にする**
毎日ゼロから考えるのは続かない。月1回30個生成して、選んでスケジュールに入れる。

この3つだけやっても、運用の安定感が変わります。

戦略設計のプロンプト全文は有料パートに入れましたが、無料パートのプロンプト例だけでも試してみてください。「AIに任せる」ではなく「AIと設計する」感覚でやると、運用が続きます。

Threadsはまだ伸びしろがある。今始めると、半年後に差がつきます。
