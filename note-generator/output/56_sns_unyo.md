# AIでSNS投稿を自動化したら運用時間が週5時間から30分になった

---

## 「また今日も投稿できなかった」

正直に言います。

去年の秋ごろ、SNS運用がしんどくて、週3日以上サボってました。

Xを開くたびに「何か投稿しなきゃ」と思うのに、ネタが浮かばない。書き始めても文章が微妙で消す。気づいたら1時間経ってて「もうやめよう」ってなる。

これを毎週繰り返してました。

沖縄で会社員をしながら副業でAI活用の発信をしているんですが、発信者なのに発信が続かないという、なんとも恥ずかしい状況です。

そのころの週間SNS運用時間を計ったら、だいたい5時間前後。ネタ出しに1時間、文章を書いては消しを繰り返して2時間、投稿タイミングを考えて30分、過去の反応を確認して30分… という感じで、時間だけは使うのに成果が出ない。

それが今は週30分以内に収まっています。

劇的に変えたのは、ChatGPTとClaudeを組み合わせた「SNS投稿の半自動化」です。

今日はその仕組みと、実際に使ってみてどうだったかを書きます。

---

## SNS運用に5時間使ってた自分の話

少し背景を話させてください。

自分はKindleを8冊出版していて、副業ではAI活用とアプリ開発の情報を発信しています。フォロワー数は多くはない。でも「少数でもちゃんと届く発信」を目指してます。

問題はネタ切れとライティングの時間コストでした。

Kindle出版した直後は発信ネタが豊富なんです。でも2週間もすると「何書けばいいんだっけ」ってなる。毎日同じような投稿してもインプレッションは伸びないし、エンゲージメントも落ちる。

試したこと：

- コンテンツカレンダーを作る → 2週間で崩れる
- 投稿テンプレートを用意する → 全部同じ見た目になってつまらない
- まとめて書き溜める → 「今日は書く気分じゃない」で溜まらない

何をやっても続かない。

「自分に発信の才能がないのか」と思い始めた時期もあります。でも、たまにバズる投稿があるんですよ。そういう投稿の共通点を振り返ると「書くのにほとんど時間がかかっていない」ことが多かった。

つまり、時間をかけることと質が高いことは比例しないんだと気づきました。

## AIを使い始めた最初の失敗

最初にやったのは「ChatGPTにXの投稿を書かせる」という、誰でも思いつく方法でした。

結果：全然使えませんでした。

文体がよそよそしい。なんか丁寧すぎる。「〜と言えるでしょう」とか「有効な手段の一つです」みたいな、自分では絶対使わない言い回しが出てくる。

投稿してみたら反応が明らかに低かった。フォロワーの人から「なんか今日の文体違う」と言われたこともあります。

AIに丸投げするのは無理だと実感しました。

ただ、ここで気づいたことがあります。「書かせる」のが問題なのであって、「考えさせる」のは使えるんじゃないかと。

ネタを生成するのはAI、文章は自分でサクッと書く、という分業が効く可能性がある。

そこからやり方を変えました。

---

## 週5時間の壁を破った「分業モデル」

試行錯誤した結果、今の自分の運用はこんな流れです。

**① ネタ出し（週1回、15分）**
毎週月曜日にClaudeに今週のネタリストを出させる。自分のテーマ（AI・副業・アプリ開発）に沿って、7〜10個のトピックを出力させる。ここで選ぶだけ。

**② 下書き生成（1投稿あたり5分）**
選んだトピックをもとに「ざっくりな下書き」をAIに書かせる。これは100%そのまま使うわけじゃなく、「素材」として使う。

**③ 自分でリライト（1投稿あたり3〜5分）**
AIの下書きを見ながら、自分の言葉に直す。「〜でしょう」を「〜だと思う」に変える。具体的な自分の体験を1行足す。これだけで文体が揃う。

**④ 予約投稿（週1回、10分）**
Buffer（無料プランで使ってる）に1週間分をまとめてセット。あとは自動で流れる。

このモデルにしてから、週の運用時間が30分以下に収まるようになりました。

削れたのは「ネタを悩む時間」と「ゼロから文章を書く時間」の2つです。

この2つで4時間以上取られてたんだと気づいたとき、正直驚きました。

---

## 自分の文体をAIに覚えさせるのが鍵だった

最初の失敗で学んだ「文体問題」の解決策も共有します。

結論から言うと、過去の自分の投稿をAIに読み込ませることで解決しました。

Claudeに対して、自分のXの過去投稿を20〜30個貼って「この文体の特徴を分析してください」と頼みます。すると「短い文を使う、数字を具体的に入れる、一人称は『自分』、語尾は〜だった・〜になったが多い」みたいに分析してくれます。

その分析結果をプロンプトの冒頭に組み込むと、出力される文章が自分の雰囲気に近づきます。

完全には一致しないけど、リライトが「文体を変える作業」から「細部を調整する作業」になる。これだけで時間が半分以下になりました。

正直、プロンプトって公開するのを迷いました。

「自分の差別化要素が減る」と思ったからです。でも考えてみたら、プロンプトよりも「自分の体験をどう入れるか」の方が重要で、同じプロンプトを使っても出てくる記事は人によって全然違うと気づきました。

**【ネタ出しプロンプト（週次用）】**

```
あなたはSNS発信の専門家です。

以下の条件でXの投稿ネタを10個出してください。

【テーマ】AI活用・副業・アプリ開発
【ターゲット読者】会社員で副業に興味がある30代
【発信者の特徴】沖縄在住、会社員、ChatGPT/Claude歴1年以上、Kindle8冊
【避けるテーマ】マルチ商法、仮想通貨、怪しい副業

各ネタは以下の形式で出してください：
- トピック（一言）
- 切り口（なぜ今これを投稿するか）
- 想定リアクション（読んだ人が感じること）
```

これを月曜日の朝に回すと、10個のネタ候補が出てきます。

自分は毎週この中から4〜5個を選んでいます。全部使わなくていい。ピンとこないものは捨てる。選ぶのに1分もかかりません。

---

**【下書き生成プロンプト（投稿1本用）】**

```
以下のトピックでXの投稿文を書いてください。

【トピック】（ここにネタリストから選んだものを入れる）
【文字数】140〜200字
【文体の特徴】
- 一文が短い（30文字以内）
- 数字を必ず1つ以上入れる
- 「〜でしょう」「〜と言えます」は使わない
- 語尾は「〜だった」「〜になった」「〜だと思う」
- 体験談ベースの書き方
- 煽り表現なし

【参考にする口調】
→ 「先月、アプリのリリース告知をXだけでやってみた。結果、初日で50人が登録してくれた。告知文は3行。長く書かなくて正解だったと思ってる。」

この口調に近い文体で書いてください。
```

参考にする口調の部分、ここが大事です。

自分の実際の投稿から1つ選んでコピペしておくと、出力のトーンが一気に揃います。

---

**【文体チェック用プロンプト】**

投稿を書いたあとに使うやつです。

```
以下のXの投稿文をチェックしてください。

【投稿文】
（ここに書いた文を入れる）

以下の観点で評価してください：
1. 一文が長すぎる箇所はないか（30文字超えてたら指摘）
2. 煽り表現・誇張がないか
3. 「〜でしょう」「〜と言えます」などの丁寧すぎる語尾がないか
4. 数字が入っているか
5. 改善案があれば1〜2つ提案してください
```

これ、地味に便利です。自分では気づかないクセを毎回指摘してくれます。

「と言えるでしょう」は癖で入れがちなのに、チェックしてもらうと毎回引っかかります。

数字で見てみます。

- 週の運用時間：4〜6時間（平均5時間）
- 1投稿あたりのインプレッション：平均180
- エンゲージメント率：1.2%

**自動化後（直近3ヶ月）**

- 週の投稿数：平均4.8投稿
- 週の運用時間：20〜35分（平均28分）
- 1投稿あたりのインプレッション：平均310

正直、インプレッションの伸びは投稿数が増えたことも大きいです。

でも1投稿あたりのインプレッションも上がっているのは、「文体を統一したことで、フォロワーが読みやすくなった」のが効いてると感じています。

エンゲージメント率は1.2%→2.1%。ほぼ倍になりました。

フォロワーは月12人→47人。約4倍です。

これを見て「すごい！」と思ってほしくはなくて。数字よりも「週5時間を30分に減らしながらこの結果」という部分を伝えたいです。

時間を増やすことなく、質と量が上がった。ここが一番の変化です。

## ネタ切れを防ぐ「ストックシステム」

自動化と並行して作ったのが「ネタストック」の仕組みです。

ネタ出しを週1回やってますが、それでも突発的にネタが思いついたときのために、Notionにネタメモを作っています。

使い方はシンプルで、気づいたことをその場でスマホからメモするだけ。

- 今日うまくいったこと
- 仕事中に感じた違和感
- アプリ開発で詰まったポイント
- 読んだ本で刺さった一文

この4ジャンルに分けてメモしています。

月曜日にClaudeでネタ出しするとき、このストックから「最近気になってること」を1〜2個追加で渡します。

するとAIが出すネタリストに、自分の実体験が混ざった角度のネタが入ってくる。これが反応良い投稿になることが多いです。

「AIが考えたネタ」と「自分の体験から来たネタ」のハイブリッドが強いと気づいたのは2ヶ月前です。

## Threadsへの展開も同じ仕組みでできた

Xで仕組みが安定してきたタイミングで、Threadsにも同じモデルを適用しました。

Threadsは文字数制限がXと違うので、プロンプトの「文字数」の部分を変えるだけです。

```
【文字数】300〜400字（ThreadsはXより長めでOK）
```

プラットフォームが変わっても、ベースのプロンプト設計は同じで使えます。

Threadsは始めて2ヶ月ですが、フォロワーが150人になりました。ゼロからのスタートです。Xよりフォロワーが増えるのが早い感覚があります。（Xが渋いだけかもですが）

## 今日から使えるテンプレートまとめ

この記事で紹介した内容を整理します。

**ステップ1：月曜日の朝にネタ出し（15分）**
ネタ出しプロンプトを使って10個リストアップ → 4〜5個選ぶ

**ステップ2：1投稿5分で下書き生成**
下書き生成プロンプトを使って素材を作る → 自分の言葉にリライト（3〜5分）

**ステップ3：文体チェック（1投稿2分）**
チェックプロンプトで確認 → 修正して完成

**ステップ4：予約投稿（週1回、10分）**
Bufferに1週間分をセット → あとは自動

合計：週30分以内

最初の1週間は「プロンプトを自分用にカスタマイズする」のに時間がかかります。自分の場合は3時間くらいかかりました。でも一度整備したら、あとは使い続けるだけです。
