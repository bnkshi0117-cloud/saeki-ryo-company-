# 発信が続かなかった自分がAIを使って180日連続投稿した方法

---

## 「今日こそ投稿しよう」と思って、しない日が続いていた

正直に言います。

去年の春まで、自分のSNSは3日に1回投稿できればいいほうでした。Xのアカウントを開いて「なにか書かなきゃ」と思いながら、結局タイムラインを眺めて閉じる。その繰り返し。

投稿しなきゃいけないのはわかってる。でも何を書けばいいかわからない。書いたとしても「これで合ってるのか」と不安になる。そうこうしているうちに時間が過ぎて、「まあ今日は仕方ないか」で終わる。

これ、会社員として副業もしながら発信もしようとしている人なら、かなり共感してもらえると思います。

そんな自分が、AIを使うようになってから180日間、毎日投稿を続けられました。今日はその話を書きます。

## 自分のSNS運用歴と、散々な試行錯誤の記録

沖縄でエンジニアの会社員をしながら、副業でKindleやアプリ開発をしています。発信はずっとやりたかった。でも続かなかった。

最初にXを始めたのは2021年頃。「毎日投稿」と意気込んで3日で途切れました。

その後もThreadsができたり、noteを書き始めたりしながら、どれも中途半端。一番続いたのが「週2〜3回投稿」で、それでも気づくと1週間空いていたりしました。

原因は2つだったと今は思っています。

**ひとつは「ネタが思いつかない」こと。**  
会社から帰ってきて、副業の作業もして、そこからさらに「今日は何を投稿しようか」と考えるのが本当にきつかった。頭がもう動いていない。

**もうひとつは「書いたものへの自信のなさ」。**  
書いてみても「これ面白いのか？」「誰が読むんだ」という気持ちが出てきて、下書きに溜めたまま消してしまうことが多かった。

この2つが合わさると、発信は止まります。

## AIを使わないSNS運用の限界、実際に感じたこと

2023年頃からChatGPTを使い始めて、しばらくは「記事の構成を考えてもらう」くらいの使い方をしていました。

ただ、これだと限界がありました。

毎回「今日の投稿ネタを考えてください」とプロンプトを打つのが面倒で、結局やらない。AIを使っているのに、使うための手間で止まってしまっていました。

あと、ChatGPTに書かせると「なんか自分っぽくない文章」になるんです。丁寧すぎて、読んでいて「これ佐伯さんが書きましたよ感」がない。自分の発信なのに、他人の文章みたいで気持ちが悪かった。

そこから「どうすれば自分の文体でAIに書いてもらえるか」を本格的に考え始めて、今の仕組みにたどり着きました。

## 実際に使っているSNS発信の自動化フロー

まず全体の流れを説明します。

自分がやっているのは「完全自動化」ではありません。AIに全部任せると文体がブレるし、実体験を書けないので、**「自分で考える部分」と「AIに任せる部分」を分けた半自動化**です。

フローはこうなっています。

```
① 週1回：ネタの種を10個出す（所要時間：15分）
② 毎朝：その日のネタを1つ選んでAIに渡す（5分）
③ AIが下書きを生成（2〜3分）
④ 自分で一文だけ手を入れて投稿（5分）
```

合計で1日あたり10〜15分。これが現実的に続いた理由だと思っています。

以前は「毎日投稿ネタを考えながら書く」をやろうとしていたので、それが無理でした。「考える」と「書く」を同じタイミングでやると、どちらも中途半端になります。

## ネタ切れを防ぐAI活用法：週1回の「ネタ出し会議」

週に1回、日曜の夜に15分だけClaudeと「ネタ出し会議」をします。

使っているプロンプトはこちらです。

```
あなたは私のSNS発信のアシスタントです。
私は沖縄在住の会社員で、AIと副業とアプリ開発について発信しています。
今週の私のリアルな出来事は以下の通りです。

【今週あったこと】
・〇〇（仕事で気になったこと）
・〇〇（副業で試したこと）
・〇〇（読んだ記事や本）
・〇〇（日常のちょっとした気づき）

この情報をもとに、X投稿ネタを10個出してください。
条件：
- 「やってみたらこうだった」という一次情報の切り口にする
- 煽り表現は使わない
- 会社員が共感できる内容にする
- 各ネタは「テーマ」と「一言メモ」の形式で
```

このプロンプトに「今週あったこと」を4〜5行書いて渡すだけで、10個のネタが出てきます。

ポイントは「今週あったこと」を自分で書く部分を絶対に省かないこと。ここが一次情報の源になります。AIは情報を整理して切り口を提案してくれるだけで、ネタの素材は自分が持ってこないといけません。

この10個をストックしておけば、平日の毎日に振り分けられます。週5投稿なら余るくらい。

## 文体・トーンを保ちながらAIに書かせるコツ

これが一番試行錯誤した部分です。

最初はプロンプトに「親しみやすい口調で書いてください」と入れていましたが、それだと「AIっぽい丁寧な文章」になってしまいます。

解決したのは、**自分の過去の投稿を5〜10本コピーして「このトーンで書いて」と渡す方法**です。

```
以下は私の過去のX投稿です。
このトーン・文体・長さを参考にして、今日の投稿を書いてください。

【過去の投稿サンプル】
（ここに実際の自分の投稿を5〜10本貼る）

【今日のネタ】
「AIを使ってネタ出しをしたら週1回15分で足りるようになった話」

【補足情報】
・以前は毎日ネタを考えていて30分以上かかっていた
・今は日曜夜だけ考えてあとは投稿するだけ
・時間が減っただけでなく「今日何書こう」という焦りもなくなった
```

このプロンプトを使うと、自分の文体に近い下書きが出てきます。

完璧には合いませんが、「ここだけ自分の言葉に直す」という作業が5分もあればできる。むしろ「直す」という作業のほうが「ゼロから書く」より圧倒的に楽です。

## 「文体ファイル」を作っておくと楽になる

毎回過去投稿を貼るのは手間なので、自分の文体をまとめた「文体ファイル」を一度作ってしまうことをおすすめします。

自分が作ったファイルの中身はこんな感じです。

```
【佐伯亮の文体ルール】
- 一文は短く。長くても50文字以内。
- 「やってみたらこうだった」という言い方をよく使う
- 数字は具体的に（「30分が5分に」「3回試して2回成功した」）
- 「最強」「革命」「爆速」は使わない
- 結論は最初か最後に来る
- 沖縄にいることや、会社員であることが滲み出るとベスト
- 読者が「わかる〜」と思える共感ポイントを一つ入れる

【よく使うフレーズ】
・「正直に言います」
・「これ、自分だけかと思ってたけど」
・「やってみたら〇〇だった」
・「というのが実態で」
・「今日からできること：」
```

このファイルをClaudeのプロジェクト機能に入れておくと、毎回のプロンプトがシンプルになります。「文体ファイルの通りに書いて」だけで通じるようになります。

## 実際の投稿パフォーマンスデータ（180日分）

数字を公開します。誇張なし、実測値です。

**AI活用前（3ヶ月平均）**
- 投稿頻度：週2〜3回
- インプレッション：1投稿あたり平均120〜300
- エンゲージメント率：0.8〜1.2%
- フォロワー増加：月+20〜40人

**AI活用後（最初の3ヶ月）**
- 投稿頻度：毎日（180日中176日達成）
- インプレッション：1投稿あたり平均280〜850
- エンゲージメント率：1.8〜3.1%
- フォロワー増加：月+120〜180人

インプレッションは約2〜3倍になりました。ただしこれは「毎日投稿するようになったから」という単純な理由が大きいと思っています。アルゴリズムは頻度を見ている実感があります。

エンゲージメント率も上がっていますが、これは「文体が安定した」ことが理由だと感じています。以前はモチベーションによって投稿の質がバラバラでした。AI活用後は「最低ライン」が担保されるようになりました。

4日投稿できなかったのは沖縄の台風シーズンで停電したのが2日、あとは単純に忘れた日が2日です。

## バズった投稿とそうでない投稿の違い

180日やってみてわかったのは、バズるかどうかはほぼ「共感できる切り口かどうか」で決まるということです。

**伸びた投稿のパターン**
- 「失敗した話＋そこから気づいたこと」
- 「以前は〇時間かかっていたのが今は△分になった」という具体的な変化
- 「これ自分だけかと思ってたら意外と多かった」という共感誘発系

**伸びなかった投稿のパターン**
- 情報をまとめただけのもの（「〇〇の使い方3選」系）
- 自分の一次情報が入っていないもの
- 長すぎて要点が見えないもの

AIに任せると「情報まとめ系」になりやすいので、そこは自分でブレーキをかける必要があります。「実体験はあるか？」「共感できるか？」の2点を必ず確認してから投稿するようにしています。

## 今日から使えるテンプレートまとめ

ここまでの内容を整理します。

**テンプレート①：週1ネタ出しプロンプト**

```
私は[あなたの職業・テーマ]について発信しています。
今週の出来事：[4〜5行で書く]
これをもとに、X投稿ネタを10個出してください。
条件：一次情報の切り口、煽りなし、共感ポイントあり
形式：テーマ＋一言メモ
```

**テンプレート②：文体統一プロンプト**

```
以下の文体ルールと過去サンプルを参考に、
今日のネタ[テーマ]の投稿文を書いてください。
文体ルール：[文体ファイルの内容]
過去サンプル：[3〜5本の自分の投稿]
補足情報：[一次情報・数字・経緯]
```

**テンプレート③：投稿前チェックリスト**

- [ ] 一次情報（自分の体験）が入っているか
- [ ] 具体的な数字があるか
- [ ] 読んだ人が「わかる」と思える一文があるか
- [ ] 煽り表現・誇張はないか
- [ ] 一文が長すぎないか（目安50文字以内）

## まとめ：続けるためには「仕組み」が先

180日やってみた結論を一行で言うと、「意志力でなく仕組みで続ける」です。

自分は意志力が強いわけじゃありません。続かなかった過去が証明しています。

AIを使って変わったのは、「毎日考えなくてよくなったこと」「自信がなくても下書きがあること」の2点だけです。でもこの2点が消えるだけで、発信のハードルが劇的に下がりました。

継続の話でよく「モチベーションを保とう」と言われますが、モチベーションは波があります。仕組みは波がありません。

使っているプロンプトのテンプレートは上でそのまま書きました。文体ファイルは自分の過去投稿5本を材料に30分あれば作れます。

今日から始めるなら、まずは「週1回のネタ出し会議」だけ試してみてください。それだけで「何を書けばいいかわからない」の8割は解消されると思います。
