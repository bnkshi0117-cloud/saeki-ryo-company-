# SNS運用でAIに任せていい部分とダメな部分の境界線

---

「AIに投稿を任せたら、なんか違う感じになった」

これ、正直めちゃくちゃわかります。
最初にChatGPTで投稿文を書いてもらったとき、内容は悪くないのに「自分っぽくない」という違和感があって。
でも逆に、全部自分で書こうとすると時間がかかりすぎて続かない。

この「どこまでAIに頼っていいのか問題」、ずっと試行錯誤してきました。

今回は、実際に自分のX（Twitter）とnoteの運用で試してきた経験をもとに、「AIに任せていい部分」と「自分でやらないとダメな部分」の境界線を整理してみます。

---

## 自分のSNS運用歴と、最初の失敗

沖縄でフルタイムの会社員をしながら、副業でAI活用やアプリ開発の情報を発信しています。

X（Twitter）のアカウントを本格的に育て始めたのは約1年半前。
最初の半年は、ほぼ毎日自分で投稿文を書いていました。

結果から言うと、続かなかったです。

朝5時に起きて投稿を考えて、仕事して、帰ってきたらもうネタが出てこない。
「今日何もない日だ…」という日が週に3〜4日あって。
そういう日は無理やり投稿するか、何も発信しないかのどちらかでした。

そこでAIを使い始めたんですが、最初のやり方が間違っていたんです。

**やってしまった失敗：AIに「投稿文を書いて」と丸投げ**

「AIを活用してSNS運用を効率化しよう」と思い立って、まずやったのが「今日のAI関連の投稿を5個作って」というプロンプトでした。

出てきた文章は確かに読みやすい。
でも、自分のアカウントに貼り付けると、なんか「企業アカウント」みたいな感じになるんですよね。

当然エンゲージメントも上がらず。むしろ下がりました。
反応が0〜1いいねの投稿が増えて、1週間で元に戻しました。

この経験から学んだのが、「AIに任せていい部分と、そうでない部分には明確な違いがある」ということです。

---

## SNS運用を3つの層に分けて考える

自分なりに整理すると、SNS運用の作業は以下の3層に分けられます。

**① アイデア・着眼点の層**
何を発信するか、どんな角度で切り取るか

**② 構成・言語化の層**
アイデアを文章に落とし込む

**③ 作業・管理の層**
投稿のスケジューリング、分析、改善案の洗い出し

結論から言うと、AIに任せていいのは「③の作業・管理層」と「②の一部」です。

そして、「①のアイデア・着眼点」は自分でやらないと、フォロワーさんには伝わりません。

---

## AIに任せたら逆効果だった部分

### 「今日の投稿テーマを考えて」系のプロンプト

これ、最初によくやりがちなんですけど、完全に逆効果でした。

AIが提案してくるテーマは「AIの最新トレンド」「生産性向上のコツ」みたいな、どこにでもある内容になりがちです。

自分のアカウントは「沖縄在住の会社員が副業でAIを使ってみた話」という一次情報が武器なのに、そのユニークさが完全に消えます。

結果、他の大量の「AIアカウント」と区別がつかなくなる。

フォロワーが増えない原因がここにあると気づくのに、3ヶ月かかりました。

### 「自分っぽい言葉」の生成

これも難しいです。

「佐伯亮のような文体で書いて」とClaude（AIアシスタント）に頼んでも、学習していない文体はそれなりにしか再現できません。

文体というのは語尾の話だけじゃなくて、「どこで改行するか」「どの単語を選ぶか」「どんなたとえを使うか」という膨大な選択の積み重ねです。

この部分をAIに任せると、読んでいる人は「なんか違う」と感じます。
それが何かははっきり言葉にできなくても、人間の感覚ってちゃんとキャッチするんですよね。

---

## AIに任せると本当に助かる部分

### ネタのリサーチと整理

「最近のAI関連の話題で、会社員が気になりそうなものを10個挙げて」
こういう使い方は効率が上がります。

全部を使うわけじゃないですが、10個の中から「あ、これ自分も先週試してみたやつだ」というものが2〜3個出てきます。

リサーチの起点としてのAI活用は、1時間かけていた作業が15分になった実感があります。

### 下書きの骨格づくり

「こんな体験を伝えたいんだけど、どんな順番で書けばいいか」という相談は効果的です。

たとえば「AIで請求書処理を半自動化した話を書きたい。何を伝えるべきか」と入力すると、「導入の動機 → 試した方法 → 躓いた点 → 解決策 → 再現性の条件」みたいな構成が出てきます。

この骨格をベースに、自分の言葉で肉付けしていく。
ここが「AIと自分の分担」として一番うまく機能しています。

### 投稿後の分析と改善案の仮説出し

「この投稿がバズって、こっちはスルーされた。違いを分析して」
という使い方も効果があります。

投稿文を2〜3個並べてAIに見せると、「語りかける主語の有無」「数字の使い方」「共感ポイントの有無」みたいな違いを整理してくれます。

もちろん正解とは限りませんが、自分一人では見落としていた角度が出てくることが多いです。

## 自分が使っているAI分担の仕組み（実例つき）

### 週1回の「ネタ仕込み」セッション

毎週日曜の夜、30分だけAIとの「ネタ出し会議」をしています。

プロンプトの型はこれです：

```
先週自分が経験したこと・試したこと：
[ここに箇条書きで3〜5個書く]

この中から、以下の条件に合うSNS投稿ネタを提案して：
- 「会社員が副業でAIを使う」文脈で共感されやすいもの
- 「やってみたらこうだった」という一次情報が使えるもの
- 失敗談や試行錯誤が含まれていると尚良い
```

ポイントは「先週の自分の体験」を必ずインプットしていること。

AIが勝手にテーマを作るんじゃなく、自分の実体験の中から「伝える価値があるもの」を探させる役割です。

これで出てきた候補のうち、2〜3個を「使えそう」と判断して翌週に投稿します。

ネタが完全にAI任せになることがないので、一次情報というアカウントの強みが保たれます。

### 投稿文を書くときの「AIとのキャッチボール」

1投稿あたり、以下の3ステップで書いています。

**ステップ1：自分で「核となる1文」を書く**

「伝えたいことの一番コア」を、まず自分の言葉で書きます。

例：「AIに投稿を丸投げすると、フォロワーには『企業っぽさ』として伝わる」

これがぼんやりしていると、AIが書く文章もぼんやりします。
一文でいいので、「これを言いたい」というのを自分の言葉で先に作ること。

**ステップ2：AIに構成と補足を出させる**

```
以下の主張をX（Twitter）の投稿として展開したい。
主張：[ステップ1で書いた一文]

・280〜300字で
・体験談ベースのトーンで
・最後に「だから自分はこうしている」という結論を入れて
・「革命」「最強」「爆速」等の誇張表現は使わない
```

**ステップ3：自分の言葉に直す**

出てきた文章を読んで、「自分ならこう言う」に書き換えます。

全部変えることもあれば、ほぼそのままのこともあります。
大事なのは「一度自分を通す」というプロセスです。

このステップ3を省くと、「企業っぽさ」が残ります。
ここだけは絶対に端折らないことにしています。

所要時間は1投稿あたり約15〜20分。
全部自分で書いていたときは30〜40分かかっていたので、半分強になりました。

## 文体・トーンを保ちながらAIに書かせるコツ

### 「自分の文章のサンプル」を毎回渡す

これが一番効果的でした。

プロンプトに毎回、過去の自分の投稿を2〜3個添付します。

```
以下は私の過去の投稿例です：
---
[投稿1]
[投稿2]
[投稿3]
---
このトーン・語調を参考にして、[今回の内容] を書いてください。
```

AIは毎回の会話がリセットされますが、サンプルを渡すことで「この人っぽい書き方」に近づけてくれます。

最初のうちは「まだちょっと違う」という感じですが、サンプルの選び方（いいねが多かった投稿を選ぶ）と指示の精度が上がるにつれて、書き直しの量が減っていきます。

### 「禁止ワードリスト」を作る

自分の場合、プロンプトに毎回追記しているのが以下のリストです：

- 「〜しましょう」は使わない
- 「実は」で文を始めない
- 「〜ですよね？」という問いかけを連発しない
- 体言止めで終わらせすぎない

これ、最初に気づいたのが「AIが書くと体言止めが多くなる」という傾向でした。
「効率化。継続。発信力。」みたいな。

自分は会話調で書くことが多いので、それが合わない。
気になるクセをリストにして禁止指示に入れるようにしてから、書き直しの頻度がかなり下がりました。

## 実際の投稿パフォーマンスの変化

以下は自分のXアカウントで、3ヶ月分の投稿パフォーマンスを比較したものです（実数値）。

**AI活用前（全部自分で書いていた期間）**
- 平均インプレッション：320/投稿
- 平均いいね数：4.2/投稿
- 週の投稿本数：3〜4本（不安定）

**AI丸投げ期間（最初の失敗期）**
- 平均インプレッション：210/投稿
- 平均いいね数：2.1/投稿
- 週の投稿本数：5〜6本（でも質が下がった）

**現在の分担型（このnoteで書いた方法）**
- 平均インプレッション：780/投稿
- 平均いいね数：11.3/投稿
- 週の投稿本数：5〜6本（安定）

数字を見ると、「AI丸投げ」よりも「全部自分」の方が実はパフォーマンスが高かったんです。

でも「全部自分」は続かない。
今の分担型は、パフォーマンスと継続性の両方が上がりました。

エンゲージメントが上がった理由を振り返ると、一番大きいのは「ネタが実体験ベースに戻ったこと」だと思っています。

## 今日から使えるSNS×AI活用テンプレート

最後に、すぐコピーして使えるプロンプトをまとめておきます。

### ①週次ネタ出しプロンプト

```
私の先週の体験・気づき：
[箇条書きで3〜5個]

これをSNS投稿のネタとして使うとしたら、どんな切り口が考えられるか、
3〜5案を提案してください。

条件：
- 「やってみたらこうだった」という体験談ベースであること
- 失敗・試行錯誤があれば積極的に使う
- 「AI活用×副業」に関心がある会社員に刺さる内容
```

### ②投稿文生成プロンプト

```
以下の主張をSNS投稿（X）として書いてください。

主張：[1文で書く]

参考にしてほしい文体サンプル：
[過去の自分の投稿を2〜3個貼る]

条件：
- 280〜320字
- 体験談ベースのトーン
- 最後に「だから私はこうしている」という結論を入れる
- 禁止ワード：「〜しましょう」「実は」の多用、体言止め連続
```

### ③投稿分析プロンプト

```
以下の2つの投稿を比較してください。

投稿A（反応が良かった）：[本文]
投稿B（反応が悪かった）：[本文]

エンゲージメントの差が生まれた理由として考えられる仮説を、
3つ挙げてください。
```

## まとめ

SNS運用でAIに任せていい部分とダメな部分、一言で言うと：

**任せていい：** 構造・リサーチ・分析・骨格づくり
**任せてダメ：** ネタの着眼点・自分の言葉・一次情報

「何を言うか」は自分で決めないといけない。
「どう書くか」はAIと一緒に考えていい。

この分担ができると、発信の質と継続性が両立します。

最初の失敗（丸投げ→パフォーマンス低下）を経験したからこそ、この境界線が見えてきました。

AIを使うほど楽になる、というのは半分本当で半分違います。
「使い方を間違えると逆効果になる」という経験も含めて、参考になれば嬉しいです。
