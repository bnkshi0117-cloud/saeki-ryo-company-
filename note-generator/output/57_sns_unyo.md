# 毎日X投稿を続けるためにClaude Codeで仕組みを作った話

---

## 「今日も投稿できなかった」が続いていた

正直に言います。

去年の自分は、X（Twitter）の投稿を週1〜2回しか続けられていませんでした。「毎日やるぞ」と決めた日から3日後には、もう止まってる。そんなのを何度繰り返したか。

「ネタがない」「疲れてる」「文章まとまらない」──言い訳はいくらでも出てきます。でも本当の理由はシンプルで、**毎回ゼロから考えて書く、という仕組みが続かなかっただけ**だったと思います。

この記事は、そのループを断ち切るためにClaude Codeで仕組みを作った話です。ツールの解説というより、自分がどう試行錯誤して、何が変わって、何が変わらなかったかを正直に書きます。

---

## 自分のX運用歴と、ずっとうまくいかなかった話

Xを本格的に使い始めたのは2022年ごろ。最初は完全に流し見専用でした。

副業をちゃんとやりたいと思い始めて、「発信しないと始まらない」という言葉を信じて投稿を始めたのが2023年の春ごろです。当時のフォロワーは200人台。

やったこと：
- 毎朝「今日の学び」をまとめる
- 話題のAIツールを試してツイートする
- インフルエンサーの投稿にリプライを送り続ける

結果：3ヶ月で500人台になりました。でも、そこで力尽きました。

なぜかというと、**続けるコストが高すぎた**んです。

「今日の学び」を毎朝まとめるには、まず学ばないといけない。仕事終わりに疲れて帰ってきて、1時間かけて記事を読んで、30分かけてポストを書いて、送信ボタンを押す──。これを365日やるのは、普通の会社員には無理です。少なくとも自分には無理でした。

そのあとしばらく放置して、またやる気が出て、また止まる。そのサイクルを2023年中に3回繰り返しました。

---

## AIを使えばいいじゃないか、と思ってから変わったこと

「AIで文章生成すればいいんじゃない？」という発想自体は、早い段階からありました。

ChatGPTが出た当初から触っていたので、「ネタをAIに考えてもらう」「文章をAIに書かせる」はすぐ試しました。でも、これがうまくいかなかった。

何が問題だったかというと、**生成した文章が「自分っぽくない」**んです。

語尾、言葉の選び方、情報の切り取り方──全部が微妙にズレてる。読んで「違う」と感じると、大幅に書き直すことになる。それなら最初から自分で書いたほうが早い、という結論になって、またAIを使わなくなる。

これを解決したのが、Claude Codeとの組み合わせでした。

---

## Claude Codeで「仕組みを作る」という発想に転換した

去年の秋ごろ、Claude Codeを使い始めました。

最初はアプリ開発のコーディング補助として使い始めたんですが、ある日「これ、SNS運用にも使えるんじゃないか」と気づきました。

Claude Codeの特徴は、**CLAUDE.mdというファイルにルールやコンテキストを書いておくと、それを踏まえた上で動いてくれる**ことです。つまり、「自分の文体」「投稿の型」「使っていいネタ・使いたくないネタ」を一度ちゃんと定義してしまえば、毎回ゼロから指示しなくていい。

ここで発想が変わりました。

「AIに毎回いい文章を書かせる」じゃなくて、「一度ちゃんと仕組みを作れば、あとは流れる状態を作る」。

それがClaude Codeでできることだと思いました。

---

## 実際に作った仕組みの概要

具体的に何をやったか、大まかに説明します。

**ステップ1：自分の投稿を30本分析する**

過去にいいねが多かった投稿、自分が「これは良かった」と思う投稿を30本選んで、Claude Codeに渡しました。「この投稿の共通点を分析して、投稿の型を言語化してほしい」と依頼。

出てきた分析が結構精度高くて、自分では気づいていなかったパターンが見えました。たとえば「共感→具体的な失敗談→転換点→学び」という流れが、エンゲージメントが高い投稿に多い、とか。

**ステップ2：CLAUDE.mdに自分の型を書く**

その分析結果をベースに、CLAUDE.mdを書きました。文体のルール、禁止ワード、投稿の長さの目安、使っていいネタのカテゴリ──全部入れました。最初のバージョンは400字くらいでしたが、今は1,200字くらいになっています。

**ステップ3：ネタのストックを作る仕組みを作る**

「ネタがない」を解決するために、ネタのインプット→ストック→投稿化、というフローを作りました。これが一番効いた部分です。詳しくは有料パートで書きます。

この3ステップを組み合わせてから、投稿頻度が週1〜2回から週5〜6回になりました。今は約2ヶ月、ほぼ毎日投稿を続けています。

---

## 変わったこと、変わらなかったこと

正直に書きます。

**変わったこと：**
- 投稿を考える時間が1日あたり40〜50分から10〜15分に減った
- 「何を書こう」で詰まる回数が激減した
- 文体のブレが減った（自分でも読み返してそう感じる）

**変わらなかったこと：**
- フォロワーが急激に増えるわけではない
- バズる投稿が出る確率は変わらない
- 仕組みを維持する手間はゼロじゃない

仕組みを作ったからといって、発信が「自動的に結果を出す」わけじゃないです。でも、「続けられるようになった」という変化は本物です。続けることで少しずつ積み上がっている感覚があります。

## 有料パート：仕組みの全体像を公開します

### 1. CLAUDE.mdに書いていること

CLAUDE.mdは、Claude Codeに「自分のことを覚えさせる」ファイルです。ここに何を書くかで、生成される文章の精度がまるで変わります。

自分のCLAUDE.mdには、大きく4つのセクションがあります。

**① 投稿者プロフィール**

```
## 投稿者プロフィール
- 名前：佐伯亮
- 居住：沖縄
- 職業：会社員（副業でAI活用・アプリ開発）
- 発信テーマ：AI × 副業 × 実体験
- トーン：カジュアル、等身大、煽らない
```

これだけ書いても最初は「キャラクターとして再現できない」と感じていました。効いたのは、次のセクションです。

**② 文体ルール**

```
## 文体ルール
- 一文は60文字以内
- 「やってみたらこうだった」を必ず含める
- 「革命」「最強」「爆速」は使わない
- 失敗談・迷いを正直に書く
- 具体的な数字を使う（「たくさん」→「3時間が30分に」）
- 語尾は「です・ます」ベース、たまり口語あり
```

これを入れてから、生成される文章が「自分が書いた文章に近い」と感じるようになりました。特に「失敗談・迷いを正直に書く」というルールは重要で、AIがつい書きがちな「うまくいった話だけ並べる」投稿を防げます。

**③ 投稿の型（フォーマット）**

```
## 投稿の型
【共感型】
- 行1：「〇〇が続かない人、いませんか？」
- 行2〜3：自分もそうだった具体的なエピソード
- 行4〜5：転換点（何を変えたか）
- 行6〜7：今どうなっているか（数字あり）
- 行8：締め（問いかけ or 教訓）

【実験報告型】
- 行1：「〇〇を試してみました」
- 行2：何をやったか（具体的な手順）
- 行3〜4：結果（数字あり）
- 行5〜6：感想・気づき（失敗も含む）
- 行7：まとめ or 次にやること
```

この型を定義しておくと、「今日は共感型で書いて」「今日は実験報告型で」と一言指示するだけで、型を守った投稿案が出てきます。

**④ 禁止事項**

```
## 禁止事項
- 「月〇万円」「副業で稼ぐ」系の煽り
- 根拠のない断言（「〇〇すれば必ず〜」）
- ハッシュタグの多用（投稿内に入れない）
- 3行以上連続する体言止め
```

禁止事項を明示的に書くのは大事です。AIは「良かれと思って」煽り気味の表現を入れてくることがあります。それを防ぐために、ネガティブルールとして書いておく。

---

### 2. ネタ切れを防ぐストック術

「ネタがない」の正体は、「インプットが投稿に変換されていない」ことです。

自分は以下のフローで解決しました。

**フロー：インプット → メモ → 素材化 → 投稿化**

**ステップ1：日常のインプットをメモに残す**

仕事中・通勤中・読書中に「これ投稿できそう」と思ったことを、その場でiPhoneのメモアプリに一行だけ書く。文章にしなくていい。キーワードだけでいい。

例：
- 「Claude Codeで30分かかってた作業が5分になった」
- 「投稿続かない原因、ゼロから考えるからだと気づいた」
- 「Kindleの印税、今月また少し上がってた」

これを1日1〜2個貯めるだけ。「投稿を書く」じゃなくて「メモを残す」にハードルを下げています。

**ステップ2：週に1回、Claude Codeに素材化してもらう**

週末に10〜15個のメモをClaude Codeに渡して、こう指示します。

```
以下のメモを見て、X投稿のネタとして使えそうな素材を整理してください。
CLAUDE.mdのルールに従って、各メモに「どの型で投稿できるか」を付けてください。

[メモリスト]
```

これで「今週のネタ候補リスト」ができます。10個のメモから7〜8個が使える素材になる感じです。

**ステップ3：毎朝5分でその日の投稿を完成させる**

朝、ネタ候補リストから1個選んで、こう指示します。

```
以下の素材で、共感型の投稿を作ってください。
300文字以内、CLAUDE.mdのルールに従って。

素材：「Claude Codeで30分かかってた作業が5分になった」
```

出てきた案を読んで、気になる部分だけ修正。平均5〜8分で完成します。最初は「自分で書いたほうが早い」と感じることもありましたが、1ヶ月続けると手が慣れて、修正も減ってきました。

---

### 3. 文体を保ちながらAIに書かせるコツ

最初に失敗したのが、「文体がずれる」問題です。今は3つのコツで解決しています。

**コツ1：自分の過去投稿を「例示」として渡す**

指示の最後に「参考投稿」を1〜2本貼り付けます。

```
以下の投稿と同じトーンで書いてください：

[参考投稿1]
毎日投稿を続けようとして3日で止まる、ってのを去年3回繰り返した。
原因はシンプルで、毎回ゼロから考えてたから。
仕組みを作ったら変わった。続けるって、やる気じゃなくて設計の問題だと思う。
```

これで「ああ、このくらいの温度感ね」とClaudeが掴んでくれます。CLAUDE.mdだけより精度が上がります。

**コツ2：修正は「差分」で指示する**

「全体的に書き直して」じゃなくて「3行目の語尾を体言止めに変えて」のように差分で指示します。全体を作り直させると、文体がズレやすい。小さな修正を積み重ねるほうが仕上がりが安定します。

**コツ3：「これは使えない」という投稿も記録しておく**

生成した中で「これは自分じゃない」と感じた投稿を、CLAUDE.mdの「NG例」セクションに追加していきます。最初はNGセクションが空でしたが、今は5〜6パターンのNG例が溜まっています。これが精度向上に一番効きました。

---

### 4. 実際の投稿パフォーマンスデータ（2ヶ月分）

仕組みを本格的に使い始めた2024年10月〜11月のデータを公開します。

**10月（仕組み導入初月）**

- 投稿数：38本（月あたり）
- 総インプレッション：約28,000
- 平均エンゲージメント率：2.1%
- フォロワー増加：+67人

**11月（慣れてきた月）**

- 投稿数：44本
- 総インプレッション：約41,000
- 平均エンゲージメント率：2.8%
- フォロワー増加：+89人

インプレッションが1.5倍近く伸びた理由は、投稿数が増えたことと、型を使い始めてエンゲージメント率が上がったことの2つだと思っています。

特に「共感型」の投稿は平均エンゲージメント率が3.2%と高め。「実験報告型」は拡散されやすい傾向がありました。

ただ、フォロワー数は「バズった」とは言えない増え方です。仕組みを作っても地道な積み上げは変わらない、というのが正直なところです。

### 5. 今日から使えるX投稿テンプレート

3パターンのテンプレートをそのまま使える形で公開します。[ ]の部分を自分のネタに差し替えてください。

**テンプレート①：共感型**

```
[続かないと感じていること]、ありませんか？

自分も[具体的な失敗回数・期間]繰り返してた。

変えたのは[やり方・仕組みの1点]だけ。

今は[具体的な現状・数字]になってる。

続けるって、やる気じゃなくて[教訓を一言で]だと思う。
```

**テンプレート②：実験報告型**

```
[ツール名 or 手法]を[具体的な期間]試してみた。

やったこと：[手順を1〜2行で]

結果：[数字あり]

気づき：[失敗 or 予想外のこと]

次は[次にやること]をやってみる。
```

**テンプレート③：学び共有型**

```
[テーマ]について気づいたこと。

・[学び1]
・[学び2]
・[学び3]

全部[実体験ベースのひとこと]から来てる。

[締めの問いかけ or 宣言]
```

この3つをローテーションして使うだけで、投稿の型が安定します。Claude Codeに「テンプレート①で今日のネタを投稿化して」と指示するのが、一番速いやり方です。

## まとめ

仕組みを作ることで変わったのは、「毎日投稿できるようになった」ことです。フォロワーが急増したわけじゃない。バズり方が変わったわけでもない。

でも、続けることでじわじわ積み上がっている感覚は、以前にはなかったものです。

CLAUDE.mdを作る・ネタをストックする・型を使う、この3つをセットにするだけ。仕組みが回り始めれば、「今日何を書こう」で詰まる時間がなくなります。

ツールや設定は一度作れば、あとは更新するだけです。最初の1〜2時間を使って仕組みを作れば、毎日の10〜15分で投稿が完成する状態になります。

試す価値はあると思います。
