# AI副業で月3万円を安定させるまでにやった7つのこと

---

## はじめに

「AIを使えば副業で稼げる」という話、あなたも一度は聞いたことがあるはずです。

でも実際に動いてみると、思ったより時間がかかる。思ったより稼げない。思ったより何をすればいいかわからない。

僕も同じでした。

沖縄でサラリーマンをしながらAI副業を始めて、最初の2ヶ月は月収5,000円にも届かない状態が続きました。「AIがあれば誰でも稼げる」みたいな情報に踊らされて、迷走した時期もあります。

でも今は月3万円前後を安定して稼げるようになりました。「月3万円」って聞くと地味に感じるかもしれません。でも沖縄の地方サラリーマンにとって、手取りが毎月3万円プラスになるのは体感でかなり違います。外食の回数が増えたし、読みたい本を迷わず買えるようになった。

この記事では、その3万円を安定させるまでに実際にやったことを7つ、具体的に書きます。「やってみたらこうだった」という実体験ベースです。

---

## AI副業の現実：半分本当で半分嘘

「AIで副業が簡単になった」は、半分は本当です。

ライティングの速度は上がりました。ChatGPTやClaudeを使えば、1,500字の記事が1時間かからず書けます。以前は同じ量を書くのに3〜4時間かかっていたので、体感で3倍以上速くなった感覚があります。

でも「簡単に稼げる」は嘘です。

AIはあくまでツールです。何を作るか、誰に届けるか、どう継続するか、それを決めるのは全部自分です。AIが稼いでくれるわけじゃない。「AIを使って、自分が稼ぐ」という構造を理解していないと、いつまでも迷走します。

僕が最初に失敗したのはまさにそこでした。「ChatGPTに記事を書かせればいい」と思っていた。でもそれだと、クオリティが低い、個性がない、差別化できない。結果として売れない、という流れになります。

AIと自分の役割を正しく分けること。それが安定して稼ぐための前提です。

## 僕の副業歴とAIを使い始めたきっかけ

副業を始めたのは2021年ごろです。最初はせどりを試みましたが、沖縄だと送料がネックで続きませんでした。

次にWebライティングを始めて、クラウドワークスで細々と稼いでいました。月1〜2万円程度。でもこれは純粋に時間と労力を売る仕事で、スケールしないと感じていた。

ChatGPTが話題になり始めた2023年初頭から、ライティングにAIを組み込むようになりました。最初は補助的に使う程度だったのが、徐々に「自分の仕事のどこにAIを入れると効率が上がるか」を考えるようになった。

その過程で見えてきたのが、今回書く7つのことです。

### やったこと①：「稼ぐ手段」を1つに絞った

最初の失敗は、あれこれ手を出しすぎたことです。

- note販売
- Kindle出版
- SEOライティング案件
- 画像生成販売
- 動画台本制作

全部同時に試していました。結果、全部中途半端になった。

ある月の収益を振り返ると、note：0円、Kindle：800円、ライティング案件：3,200円、画像生成：0円、動画台本：1,500円。合計で5,500円。時間は毎日2〜3時間使っていたので、時給換算すると400円以下です。

これを見てさすがに「集中しないとダメだ」と思いました。

僕が最終的に選んだのは「SEOライティング案件＋note販売」の2本柱です。理由は、ライティング案件で安定収入を作りながら、noteでストック収益を積み上げるという組み合わせが、サラリーマンの本業と相性がよかったから。

1つに絞ると、スキルが深まる速度が明らかに違います。

---

### やったこと②：AIの使い方を「生成」から「編集」に変えた

最初の頃、僕はAIに「記事を書いて」と投げていました。

でもAIが生成した文章をそのまま使っても、だいたい通らないか、低評価になります。クライアント側も「AIっぽい文章」に慣れてきているので、素のAI出力はすぐばれます。

今の使い方は逆です。

まず自分が「構成と要点」を書く。そこをAIに渡して「肉付けしてもらう」。その後、自分で読み直して「自分の言葉に整える」。

この流れにしてから、クライアントからの評価が明らかに上がりました。「読みやすい」「個性がある」というフィードバックをもらえるようになった。

AIは「文章を速く書くツール」じゃなくて「自分の考えを整理して表現するツール」という使い方が、僕には合っていました。

作業時間で言うと、1,500字の記事を書く時間が3.5時間→1.2時間に短縮されました。全部AIに任せた場合より遅いかもしれませんが、クオリティが段違いです。

---

### やったこと③：最初の3ヶ月は「量より継続」を優先した

副業を本格的に軌道に乗せようとした最初の3ヶ月、毎日何かアウトプットを出すことだけを目標にしました。

記事を書く、プロンプトを試す、案件に応募する。何でもいいから、毎日1つ動く。

この時期は月収3,000〜8,000円をうろうろしていました。正直しんどかった。でも継続することで見えてきたものがあります。

- 自分が得意なライティングのジャンル
- どのクライアントと相性がいいか
- どんなnoteが読まれるか

これはやらないと絶対にわからない情報です。

僕は沖縄の地方在住というのもあって、リアルでの副業機会が少ない。だからこそオンラインで稼ぐ仕組みを作る必要があった。3ヶ月の継続が、後の安定につながったと思っています。

## やったこと④：月収の推移と、転換点になった出来事

正直に数字を出します。

| 月 | 月収 | 主な収入源 |
|---|---|---|
| 1ヶ月目 | 3,200円 | ライティング案件のみ |
| 2ヶ月目 | 5,800円 | ライティング＋note初売れ |
| 3ヶ月目 | 7,400円 | 同上 |
| 4ヶ月目 | 12,600円 | 継続案件獲得 |
| 5ヶ月目 | 18,200円 | Kindle出版追加 |
| 6ヶ月目 | 24,500円 | note販売強化 |
| 7ヶ月目 | 31,800円 | 月3万超え初達成 |
| 8ヶ月目〜 | 28,000〜35,000円 | 安定期 |

転換点は4ヶ月目の「継続案件獲得」です。

それまでは単発案件ばかりでした。1記事いくら、という形で受けていた。これだと毎月ゼロから案件を探す必要があって、精神的にも時間的にも消耗します。

転換のきっかけは、クライアントに自分から「月10記事の定期契約ができますか」と聞いたことです。最初は断られると思っていました。でも「むしろ助かる」という返答が来た。クライアント側も毎回ライターを探すのが手間なんですよね。

この継続契約が月1万円の固定収入になり、そこから精神的な余裕が生まれました。余裕があるとnoteも書けるし、Kindle原稿も進む。収入の安定が、さらなる収入につながるサイクルができました。

**継続案件を取るためにやったこと：**

- 単発案件を必ず期日より1日早く納品する
- 納品時に「改善点があれば教えてください」と一言添える
- 3〜4回納品したら「継続的にお願いできますか」と聞く

これだけです。特別なスキルは必要ありませんでした。

## やったこと⑤：実際に使ったツールと設定

僕が今も使っているツールと、具体的な使い方を書きます。

**① Claude（Anthropic）**

メインのライティング補助に使っています。ChatGPTより文章の自然さが高いと感じています。個人的に長文の構成整理が得意な印象。

月20ドル（Proプラン）を払っています。これは経費として割り切っています。

**使い方の基本プロンプト（ライティング補助用）：**

```
あなたはプロのWebライターです。
以下の要点をもとに、読者に自然に届く文章を書いてください。

【テーマ】〇〇
【対象読者】〇〇に興味がある20〜40代
【要点】
- 〇〇
- 〇〇
- 〇〇

条件：
- 一文60字以内
- 専門用語は使わない
- 実体験っぽい口調で
- 800字程度で
```

このプロンプトで生成した文章を、自分の実体験に合わせて書き直します。AIが書いた7割を自分の言葉で3割上書きする感覚です。

**② Notion AI**

ノートとAIが一体になっているので、メモと記事作成を同じ場所でできます。アイデアをメモしたらそのままAIに「これを膨らませて」と頼める。

月10ドルの追加料金ですが、ワークフローがシンプルになるので使っています。

**③ クラウドワークス**

ライティング案件のメイン受注先です。ランサーズも試しましたが、クラウドワークスの方が沖縄在住のリモートワーカーには案件が多い印象でした。

プロフィールに書いた一言で反応率が変わりました。「AI補助で高速・高品質なライティングが可能」と明記してから、声がかかる頻度が上がりました。AI使用を隠すのではなく、むしろ強みとして打ち出す戦略です。

**④ note**

ストック収益の柱です。有料記事の売れ行きは最初は月数百円でしたが、継続的に投稿することで少しずつ積み上がっています。

重要なのは「無料記事でファンを作ってから有料を出す」という順番です。最初から有料記事を出しても売れません。僕は無料記事を10本書いてから、初めて有料記事を出しました。

## やったこと⑥：失敗したパターンと原因分析

うまくいったことだけ書くのは不誠実なので、失敗も正直に書きます。

**失敗①：AIで画像を生成して販売しようとした**

Midjourneyで生成した画像をSNSで販売しようとしました。結果は2ヶ月で売上0円。

原因は「誰が買うのか」を考えていなかったこと。画像の用途、購入者のニーズ、競合との差別化。何も考えずに「きれいな画像を作れば売れる」と思っていました。

画像生成販売は「センスのある人が継続的にニーズを研究する」必要がある分野です。ライティングバックグラウンドの僕には向いていなかった。得意なことを伸ばす方が早いと気づいて撤退しました。

**失敗②：SEO記事をAIに全任せして低評価をもらった**

案件が増えて忙しくなった時期、効率化のためにAI生成をそのまま納品したことがあります。

クライアントから「前回と文体が違う」「読みにくい」というフィードバックが来ました。継続案件だったのに、この件で関係が冷えてしまった。

AI出力をそのまま使うのはリスクです。特に継続案件では、自分の文体の一貫性がクライアントの信頼につながっています。

**失敗③：Kindle出版で「売れる本」より「書きたい本」を書いた**

Kindle出版を始めた時、「自分が興味あること」を書きました。沖縄の地方生活とリモートワークについて。

売上は初月2,000円、次月から月数百円に落ちました。

Kindle市場ではニーズのあるテーマを選ぶことが前提です。「書きたいこと」と「読まれるもの」は別物。今は出版前にAmazonで同ジャンルのベストセラーを5冊読んで、ニーズを確認してから書き始めます。

## やったこと⑦：再現性のある仕組みの作り方

最後に、月3万円を安定させるための仕組みを整理します。

「安定」のポイントは収入の柱を2種類に分けることです。

**フロー収入：毎月働いて得る収入**
→ライティング案件の継続契約

**ストック収入：一度作ったものが積み上がる収入**
→note有料記事、Kindle本

フロー収入だけだと、病気や本業の繁忙期に副業が止まった瞬間に収入が0になります。ストック収入だけだと、最初の期間が長くて心が折れます。

2つを組み合わせることで、精神的な安定と収入の安定が同時に生まれます。

**具体的な時間配分（平日1.5〜2時間の場合）：**

- 月曜・水曜・金曜：ライティング案件（フロー）
- 火曜・木曜：note記事またはKindle原稿（ストック）
- 土曜：振り返りと翌週の計画（30分）
- 日曜：完全休み

この配分で本業に支障なく続けられています。本業との両立で大事なのは「絶対に本業を犠牲にしない」という原則です。副業が本業に影響し始めたら、副業のペースを落とす。これを守っています。

## 初月から動けるロードマップ

まとめとして、読んでくれた方が明日から動けるロードマップを書きます。

**1週目：環境を作る**
- ClaudeまたはChatGPTの有料プランに登録（月20ドル）
- クラウドワークスのプロフィールを整える
- noteアカウントを開設して自己紹介記事を書く

**2〜3週目：小さく稼ぎ始める**
- クラウドワークスでテスト案件を3件受ける（単価より実績重視）
- noteに無料記事を3本投稿する

**4週目：継続の仕組みを作る**
- テスト案件のクライアントに継続契約を打診する
- noteで初めての有料記事を出す（500〜1,000円設定）

**2〜3ヶ月目：積み上げる**
- ライティング案件を月1〜2本ずつ増やす
- note記事を月4本以上投稿する（無料3＋有料1）

**4〜6ヶ月目：安定させる**
- 継続案件を2〜3社に増やす
- noteの有料記事を10本以上にする
- Kindle出版を検討する（ニーズ調査後）

この流れを忠実にやれば、6〜7ヶ月で月3万円の安定圏に入れると思います。僕がそうでした。
