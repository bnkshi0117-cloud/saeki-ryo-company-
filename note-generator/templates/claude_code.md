## 無料パートの構成
1. 冒頭フック：「コードが書けなくてもアプリは作れる（本当に）」
2. 導入：自分のエンジニアとしての経歴（非エンジニア目線）
3. 問題提起：従来の開発との違い、Claude Codeとは何か

## 有料パートの構成
1. 実際の開発フロー（スクショ付き）
2. Claude Codeへの指示の出し方・コツ
3. つまずいたポイントと解決策
4. リリースまでの手順
5. まとめ：非エンジニアが最初にやるべきこと
